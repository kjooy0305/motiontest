설치 및 버전 관리

  1. Unity Hub 설치 — 버전 관리·라이선스·프로젝트 허브 역할
  2. Hub에서 Installs → Add로 원하는 Unity 버전 설치 (LTS 권장)
  3. 모듈 추가: Android Build Support, iOS Build Support, WebGL 등 빌드 타겟 선택
  4. Projects → New Project로 템플릿 선택 후 생성
  5. Visual Studio(또는 Rider)를 기본 에디터로 지정: Edit → Preferences → External Tools
Unity 개인 라이선스(Personal)는 연 수익 $200,000 이하 무료. LTS(Long Term Support) 버전은 2년간 버그픽스 지원이 보장됩니다.

MyProject/
├── Assets/          ← 게임 에셋 (스크립트·씬·스프라이트 등)
│   ├── Scenes/
│   ├── Scripts/
│   ├── Prefabs/
│   └── Materials/

├── ProjectSettings/ ← 빌드·물리·레이어 설정

⚙️ 워크플로

씬과 GameObject

  1. 씬 생성: File → New Scene 또는 Project 창에서 우클릭 → Create → Scene
  2. GameObject 생성: GameObject 메뉴 또는 Hierarchy 우클릭
  3. 컴포넌트 추가: Inspector에서 Add Component 버튼
  4. 스크립트 붙이기: Project에서 .cs 파일을 Inspector로 드래그, 또는 Add Component → 스크립트 이름

프리팹 (Prefab)

재사용 가능한 GameObject 템플릿입니다. 하나를 수정하면 씬에 놓인 모든 인스턴스에 반영됩니다.

  1. Hierarchy의 GameObject를 Project 창으로 드래그 → 프리팹 생성
  2. 프리팹을 씬에 드래그하면 인스턴스 배치
  3. 파란색 이름 오브젝트 클릭 → Inspector 상단 Open Prefab으로 편집
  4. Prefab Variant: 기존 프리팹을 기반으로 일부만 다른 변형 생성 가능

빌드 과정

  1. File → Build Settings 열기
  2. 플랫폼 선택 후 Switch Platform
  3. 씬을 Add Open Scenes로 빌드 리스트에 추가
  4. Player Settings에서 회사명·앱 이름·아이콘 설정
  5. Build 또는 Build And Run 클릭
Android 빌드: Android SDK · JDK 경로를 Preferences → External Tools에 지정해야 합니다.

💻 스크립팅

MonoBehaviour 수명 주기

Awake()        // 오브젝트 생성 직후. 비활성 상태에서도 호출
OnEnable()     // 오브젝트 활성화될 때마다
Start()        // 첫 프레임 직전 (활성화된 경우)
FixedUpdate()  // 물리 업데이트 (고정 60Hz)
Update()       // 매 프레임
LateUpdate()   // Update 후. 카메라 추적 등
OnDisable()    // 오브젝트 비활성화 시
OnDestroy()    // 오브젝트 파괴 시
카메라 추적 로직은 반드시 LateUpdate()에, 물리는 FixedUpdate()에 작성하세요.

코루틴 (Coroutine) ▶
// 코루틴 시작
StartCoroutine(MyRoutine());

IEnumerator MyRoutine() {
    Debug.Log("시작");
    yield return new WaitForSeconds(2f); // 2초 대기
    Debug.Log("2초 후");
    yield return null; // 다음 프레임까지 대기
    yield return new WaitUntil(() => condition);
}

// 중단
Coroutine co = StartCoroutine(MyRoutine());
StopCoroutine(co);
