🧘 혼자 하는 게임 (솔리테어)
52장 한 묶음으로 혼자 즐기는 게임. 운과 전략이 적절히 섞인 퍼즐.
🃏
클론다이크
Klondike Solitaire
1인쉬움~중간15~30분
목표
4개의 파운데이션에 각 무늬별로 A→2→…→K 순서로 쌓아 52장 모두 올리기
준비
태블로: 7개 열에 1~7장 배분 (각 열 맨 위 카드만 앞면)
스톡: 나머지 24장은 뒤집어 덱으로
파운데이션: 우상단 4칸 (처음엔 비어 있음)
웨이스트: 스톡을 뒤집을 때 카드가 오는 곳
규칙
  1. 태블로 → 태블로: 다른 색, 내림차순으로 올릴 수 있음 (예: 빨강 7 위에 검정 6)
  2. 태블로 → 파운데이션: 같은 무늬, 오름차순 (A 먼저, 그 다음 2, 3…)
  3. 스톡 뒤집기: 1장씩(입문) 또는 3장씩(표준) 뒤집어 웨이스트로
  4. 열이 완전히 비워지면 K(또는 K부터 시작하는 그룹)만 놓을 수 있음
  5. 앞면으로 뒤집힌 카드는 자유롭게 이동 가능
예시
태블로: ♥8 위에 ♠7 올리기 (다른 색, 내림차순 ✔)
파운데이션: ♥A → ♥2 → ♥3 순서로 쌓기
스톡: 3장 뒤집으면 제일 위 카드만 사용 가능
빈 열: ♣K 또는 ♣K-♥Q-♠J 그룹 이동
🔲
프리셀
FreeCell
1인중간20~40분
목표
4개의 홈 셀에 각 무늬 A→K로 쌓기. 빈 셀을 임시 보관소로 활용
준비
8개 열에 52장 전부 앞면으로 배분 (4열=7장, 4열=6장)
프리 셀 4칸: 빈 임시 보관소
홈 셀 4칸: 최종 목적지 (A부터)
규칙
  1. 열 → 열: 다른 색, 내림차순. 이동 가능 카드 수 = (빈 프리셀+1) × 2^(빈 열 수)
  2. 열 → 프리셀: 1장만 임시 보관. 한 칸에 1장 제한
  3. 어디서든 → 홈 셀: 같은 무늬 오름차순
  4. 빈 열에는 어떤 카드든 놓을 수 있음
  5. ~99.999% 모든 배열 풀림 (5번 게임만 불가)
예시
프리셀에 ♦J 임시 보관 →
그 자리 비워 ♠Q를 ♥K 위로 이동 →
이동 가능 수: 프리셀 3칸 비어있고 빈 열 1개 = (3+1)×2 = 8장까지 그룹 이동 가능
🔺
피라미드
Pyramid Solitaire
1인쉬움5~15분
목표
피라미드의 28장 + 덱 카드를 합 13으로 짝지어 제거. 전부 없애면 승리
카드 값
A=1, 2~10 = 액면값, J=11, Q=12, K=13(단독 제거)
준비
7줄 피라미드(28장, 맨 아래 줄만 노출), 나머지 24장은 스톡
규칙
  1. 노출된 카드(위 카드가 없는 것) + 덱 상단 카드로 합 13 짝 찾기
  2. 짝이 된 두 장 또는 K 한 장을 제거
  3. 스톡을 한 장씩 뒤집어 웨이스트로. 웨이스트 상단도 사용 가능
  4. 스톡이 다 되면 한 번 뒤집어 재사용 (규칙에 따라 횟수 제한)
예시
♣K → 단독 제거
♥8 + ♠5 = 13 → 제거
♦Q + ♣A = 13 → 제거
피라미드 아랫줄: 10+3, 9+4, 8+5, 7+6 조합으로 제거
⛳
골프 솔리테어
Golf Solitaire
1인쉬움5~10분
목표
남는 카드 수(타수)를 최소화. 9라운드 해서 합산 타수가 낮은 사람이 승리 (골프처럼)
준비
7열 5장씩(35장, 전부 앞면) + 스톡 17장 (맨 위 1장 웨이스트로 공개)
규칙
  1. 웨이스트(기준 카드)에서 숫자 ±1인 태블로 카드를 올릴 수 있음
  2. 무늬 무관. 예: 기준 6이면 5 또는 7 올리기 가능 (연속 연결)
  3. K 위에 Q는 OK, K 위에 A는 불가 (순환 없음이 표준 규칙)
  4. 더 이상 낼 카드 없으면 스톡에서 한 장 뒤집어 기준 갱신
  5. 스톡 소진 후 남은 태블로 카드 수 = 점수(타수)
예시
웨이스트: 6 → 태블로 7 올리기 → 다시 8 올리기 → 9 → 10 연속 4장 제거!
막히면 스톡 뒤집어 새 기준 카드 획득
⛰️
트리피크스
TriPeaks
1인쉬움5~10분
목표
3개의 피크(정상 카드)를 포함한 모든 카드를 기준 카드 ±1로 제거
준비
3개의 소형 피라미드 형태(각 3줄, 총 28장), 나머지 24장 스톡
맨 아래 줄 카드만 노출된 상태로 시작
규칙
  1. 스톡 상단을 웨이스트로 공개 → 기준 카드
  2. 노출된 카드 중 기준 ±1이면 제거 (무늬 무관)
  3. 연속 제거 시 콤보 점수 증가 (연속 제거 ×배수)
  4. 더 낼 카드 없으면 스톡에서 뒤집기 (점수 없음)
  5. 스톡 소진 시 게임 종료. 남은 카드 수만큼 감점
예시
기준: 5 → 6 → 7 → 8 → 7 → 6 연속 6장 제거 = 콤보 보너스!
정상(피크) 카드를 제거하면 +추가 점수
👥 2인 게임
두 명이 마주 앉아 즐기는 게임. 빠른 반응부터 전략까지 다양.
⚔️
워 (전쟁)
War
2인쉬움10~30분
목표
상대방의 카드를 모두 빼앗기
준비
52장을 뒤집어 26장씩 나눔. 각자 앞에 더미 형태로 놓기
규칙
  1. 동시에 더미 맨 위 카드를 1장씩 앞면으로 공개
  2. 높은 숫자 카드를 낸 사람이 두 장 모두 가져감 (자신 더미 아래에 추가)
  3. 카드 순위: 2 < 3 < … < 10 < J < Q < K < A
  4. 전쟁 (같은 숫자): 각각 카드 3장을 엎어두고 4번째 카드 공개 → 높은 쪽이 전부 가져감
  5. 전쟁 중 전쟁도 가능 (무한 연속)
예시
A: ♠Q vs B: ♥7 → A 승리, 2장 획득
A: ♣9 vs B: ♦9 → 전쟁!
각각 카드 3장 엎기 → A: ♥K vs B: ♠6 → A가 총 8장 획득
⚡
스피드
Speed / Spit
2인쉬움5~15분
목표
손에 든 카드를 상대보다 먼저 모두 내려놓기
준비
각 26장. 각자 손패 5장 + 나머지 더미. 가운데 2개의 공유 더미(각 5장)
규칙
  1. 동시에 "스피드!" 외치고 시작 (또는 카운트다운)
  2. 가운데 두 더미 상단 카드 기준으로 숫자 ±1인 손패를 올릴 수 있음
  3. 무늬 무관. A는 K 또는 2와 연결 (순환 가능)
  4. 양손 동시 사용 가능, 선착순
  5. 둘 다 막히면 양쪽 더미에 동시에 새 카드 펼침
  6. 먼저 손패 0장이 되면 손바닥으로 더미 치며 "스피드!" → 승리
예시
가운데 더미: 6, J
내 손패: 5, 7, Q, 10 → 5(6-1) 7(6+1) Q(J+1) 10(J-1) 전부 내릴 수 있음!
👋
슬랩잭
Slap Jack
2인쉬움5~20분
목표
가운데 더미를 모두 차지하기
준비
26장씩 뒤집어 더미. 가운데 빈 공유 더미 자리
규칙
  1. 번갈아 자신 더미 맨 위를 가운데에 앞면으로 내려놓기
  2. J가 나오면 먼저 손바닥으로 가운데 더미를 치는 사람이 더미 전체 획득
  3. J가 아닌 카드를 쳤을 때 페널티: 자신 더미 최상단 카드 1장을 가운데에 추가
  4. 더미가 없어진 사람은 다음에 J가 나올 때 먼저 치면 복귀 가능
예시
A가 3 내려놓기 → B가 9 내려놓기 → A가 ♠J 내려놓는 순간
B가 먼저 손으로 탁! → B가 가운데 더미 전체(지금까지 쌓인 모든 카드) 획득

스냅
Snap
2인쉬움5~15분
목표
상대방 카드를 모두 가져가기
준비
26장씩 앞에 더미 (뒤집어 놓음)

각 4장씩, 가운데 4장 앞면 공개. A=1, 2~10=액면값, J/Q/K=포획 불가(단독 매칭만)
규칙
  1. 차례에 손패 1장으로 가운데 카드 포획:
    • 매칭: 같은 숫자 카드로 가져가기
    • 합산 포획: 손패 카드 = 가운데 여러 카드의 합 (예: 9로 4+5 가져가기)
    • 빌드: 나중에 포획하기 위해 합산 조합 만들어 두기 ("3 빌드")
  2. 포획 못하면 가운데에 1장 버리기
  3. 모든 손패 소진 시 4장씩 다시 배분 (덱 소진까지)
  4. 마지막에 가운데 남은 카드는 마지막으로 포획한 사람이 가져감
점수
카드 27장 이상=3점, ♠=1점, ♦10=2점, ♠2=1점, A=각 1점, 스윕(한 번에 전부)=1점
예시
가운데: 4, 5, 3, K / 내 손: 9, K
9로 4+5=9 포획 → K로 K 매칭 포획
가운데 3만 남아있으면 다음 차례 활용
🥃
위스트
Whist
4인(2팀)중간30~60분
목표
13트릭 중 더 많이 따내는 팀이 승리. 7트릭 이상이면 점수 획득
준비
13장씩 배분. 마지막 카드를 모두에게 공개 → 그 무늬가 트럼프. 맞은편끼리 팀
규칙
  1. 선공이 아무 카드나 내고, 나머지는 같은 무늬 따라가야 함
  2. 해당 무늬 없으면 트럼프 또는 다른 무늬 (다른 무늬는 트릭 획득 불가)
  3. 같은 무늬 중 최고 패가 트릭 획득 (트럼프가 있으면 트럼프 최고 패)
  4. 트릭 획득자가 다음 선공
  5. 7트릭=1점, 8=2점, …13=7점. 게임 목표 점수 합의(보통 5 또는 7점)
예시
트럼프: ♥ / 선공: ♠A
B: ♠7, C: ♠K, D: ♠ 없어서 ♥3(트럼프!)
→ D가 트릭 획득 (트럼프 3이 ♠A, ♠K, ♠7 전부 이김)
♠ 포커 변형 종류
같은 52장으로 즐기는 다양한 포커 변형. 패 순위는 '기본 레퍼런스' 탭 참조.

텍사스 홀덤
Texas Hold'em
2~10인중간세계 표준 포커
목표
홀카드 2장 + 커뮤니티 5장에서 최고의 5장 조합으로 승리 (또는 블러핑)
준비
딜러 버튼 지정. 왼쪽 1번째=스몰 블라인드, 2번째=빅 블라인드(강제 베팅)
게임 진행
  1. 프리플랍: 홀카드 2장 배분 → 베팅 라운드 (콜/레이즈/폴드)
  2. 플랍: 커뮤니티 3장 공개 → 베팅
  3. 턴: 커뮤니티 4번째 카드 공개 → 베팅
  4. 리버: 커뮤니티 5번째 카드 공개 → 최종 베팅
  5. 쇼다운: 남은 플레이어 패 공개 → 최고 5장 조합 비교 → 승자가 팟 획득
  6. 올인 가능. 사이드 팟 규칙 존재
예시
내 홀카드: ♠A♠K
플랍: ♠Q♠J ♥10 → 로열 플러시 완성! (♠A-K-Q-J + 필요 없음, 이미 스트레이트 플러시 성립)
턴: ♦2 / 리버: ♣3
최종 5장: ♠A♠K♠Q♠J♥10 = 로열 플러시

5카드 드로우
5-Card Draw
2~6인쉬움클래식 포커
목표
5장 중 원하는 카드를 교체해 최고 패 만들기
게임 진행
  1. 앤티(강제 베팅) 후 각자 5장 배분
  2. 1차 베팅: 콜/레이즈/폴드
  3. 드로우: 원하는 카드 버리고 같은 수 교체 (최대 3장, A 보유 시 4장)
  4. 2차 베팅: 최종 베팅
  5. 쇼다운: 패 공개 → 최고 패 승리
예시
손패: ♥K♦K + ♠7♣3♣J
♠7♣3♣J 버리고 3장 교체 → ♥K♦K + ♣K + 2장
→ 트리플 K 달성! (또는 더 운이 좋으면 포카드)

세븐카드 스터드
7-Card Stud
2~8인중간커뮤니티 없음
특징
커뮤니티 카드 없이 개인 7장으로 진행. 홀덤 이전의 표준 포커
게임 진행
  1. 써드 스트리트: 뒷면 2장 + 앞면 1장 배분. 앞면 최저 패가 브링인(강제 소액 베팅)
  2. 포스~식스 스트리트: 앞면 카드 3장 추가 (총 앞면 4장), 각 라운드마다 베팅
  3. 세븐스 스트리트(리버): 7번째 카드를 뒷면으로 배분 → 최종 베팅
  4. 쇼다운: 7장 중 최고 5장 조합 비교
예시
내 패: 뒷면♠A♠K / 앞면 ♠Q♠J♣5 / 뒷면 ♠10
7장: ♠A♠K♠Q♠J♣5♠10
최고 5장: ♠A♠K♠Q♠J♠10 = 로열 플러시!

오마하
Omaha Hold'em
2~10인중간홀덤 강화판
홀덤과의 차이
홀카드 4장. 반드시 홀카드 중 정확히 2장 + 커뮤니티 정확히 3장 사용
게임 진행
  1. 홀카드 4장 배분 (홀덤은 2장)
  2. 진행은 텍사스 홀덤과 동일: 프리플랍→플랍→턴→리버→쇼다운
  3. 쇼다운 시 반드시 홀카드 2장 + 커뮤니티 3장 조합으로만 패 구성
  4. 강한 패가 자주 나오므로 원페어·투페어로는 승리 어려움
예시
홀카드: ♠A♠K ♥Q♦J
커뮤니티: ♠Q♠J♣10 ♥2♦3
→ 사용 조합: 홀카드 ♠A♠K + 커뮤니티 ♠Q♠J♣10 = 스트레이트 (A-K-Q-J-10)
※ 홀카드 4장 모두 사용 불가! 반드시 2장만

3카드 포커
3-Card Poker
1~다수 vs 딜러쉬움카지노 게임
목표
3장만으로 딜러보다 높은 패 구성
패 순위 (3카드 전용)
스트레이트 플러시 > 트리플(3카드에서 특이하게 2위) > 스트레이트 > 플러시 > 페어 > 하이카드
게임 진행
  1. 앤티 베팅 후 플레이어·딜러 각 3장 배분
  2. 플레이어: 패 확인 후 폴드(앤티 잃음) 또는 플레이(앤티 동액 추가 베팅)
  3. 딜러 자격: Q 이상 패 보유 시 자격 있음 (없으면 앤티만 지급)
  4. 딜러 자격 있고 플레이어 승리: 앤티+플레이 베팅 1:1 지급
  5. 페어 플러스: 별도 사이드벳. 페어 이상이면 보너스 지급
예시
플레이어: ♠J♠Q♠K = 스트레이트 플러시!
딜러: ♥9♦K♣A = 하이카드 A
→ 플레이어 압도적 승리. 페어 플러스 보너스도 받음

용어설명
트릭 (Trick)한 라운드 — 각 플레이어가 1장씩 내고 최고 패가 전부 획득
트럼프 (Trump)선공 무늬를 이기는 특별 무늬. 낮은 트럼프도 다른 무늬 최고패를 이김
선공 (Lead)해당 트릭에서 첫 번째로 카드를 내는 행위 및 플레이어
팔로우 수트 (Follow Suit)선공 무늬를 따라가야 하는 규칙
버프 (Void)특정 무늬가 손패에 전혀 없는 상태 → 트럼프 낼 수 있음
슬러프 (Sluff)이길 수 없는 카드를 버리는 행위 (점수 피하기 등)
