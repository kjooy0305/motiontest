04 표(Table) — Ctrl+T
데이터 범위를 표로 변환하면: 행 추가 시 수식·서식 자동 확장, 정렬·필터 내장, 구조적 참조 사용 가능. 피벗테이블·수식의 원본은 표로 만드는 게 정석입니다.
' 구조적 참조 — 셀 주소 대신 열 이름으로 =SUM(판매표[금액]) ' 금액 열 전체 합계 (행 늘어나도 자동 반영) =[@단가]*[@수량] ' 같은 행의 단가×수량 (@=현재 행) =판매표[#머리글] ' 머리글 행
표 이름은 표 선택 → [테이블 디자인] 탭에서 변경. 요약 행(Ctrl+Shift+T)을 켜면 열별 합계·평균 드롭다운 제공.

06 셀 서식 코드 — Ctrl+1 → 사용자 지정
표시 형식은 값은 그대로 두고 보이는 모양만 바꿉니다. 구조: 양수;음수;0;텍스트 (세미콜론 구분, 뒤쪽 생략 가능)

#,##0.00

백분율
yyyy-mm-dd (aaa)

#,##0;[빨강]-#,##0;"-"
양수는 검정, 음수는 빨강, 0은 "-" 표시 — 재무 보고서 표준
000-0000-0000

@"님"

;;;

💡 엑셀 날짜의 정체: 1900-01-01 = 1 인 일련번호입니다. 그래서 날짜끼리 빼기(=B1-A1)가 되고, 시간은 소수(0.5=12:00)로 계산됩니다.

01 수학 · 통계
=SUM(A1:A10)
합계 — 범위 여러 개 가능 =SUM(A:A, C:C)
=AVERAGE(범위)

=COUNT(범위) / =COUNTA(범위)

=MAX(범위) / =MIN(범위)

02 논리 — IF 가족
=IF(조건, 참일때, 거짓일때) =IF(A2>=60, "합격", "불합격") ' 다중 조건 — IF 중첩 대신 IFS (2019+) =IFS(A2>=90,"A", A2>=80,"B", A2>=70,"C", TRUE,"F") ' TRUE = 나머지 전부 ' AND / OR 조합 =IF(AND(A2>=60, B2>=60), "합격", "불합격") ' 둘 다 만족 =IF(OR(A2="서울", A2="경기"), "수도권", "지방") ' 오류 처리 — 실무 수식의 마무리 습관 =IFERROR(VLOOKUP(...), "없음") ' 모든 오류를 대체 =IFNA(VLOOKUP(...), "없음") ' #N/A만 대체 (추천 — 다른 오류는 드러나게) ' 값 매핑 — SWITCH (2019+) =SWITCH(A2, 1,"월", 2,"화", 3,"수", "기타")

04 날짜 · 시간

연/월/일/요일 추출 — WEEKDAY는 1(일)~7(토), TEXT(A1,"aaa")로 "월" 표시가 편함

그 달 말일 — 0=당월, -1=전월 말, 1=익월 말. 말일+1=월초 패턴으로 월별 집계

=NETWORKDAYS(A1, B1, [휴일범위])

=TIME(9, 30, 0) · =HOUR / MINUTE
시각 만들기 / 추출 — 근무시간 =(퇴근-출근)*24 (시간은 하루=1인 소수라 ×24)
🔍 찾기 · 참조
VLOOKUP · XLOOKUP · INDEX+MATCH — 실무 엑셀의 심장부
01 VLOOKUP — 고전이자 표준
=VLOOKUP(찾을값, 표범위, 열번호, [일치방식]) =VLOOKUP(A2, $F$2:$H$100, 3, FALSE) ' A2 값을 F열에서 찾아 → 표의 3번째 열(H) 값을 가져옴 ' FALSE(또는 0) = 정확히 일치 — 실무에서는 거의 항상 FALSE! ' TRUE(근사 일치)를 쓰는 유일한 경우 — 구간표 (오름차순 정렬 필수) ' 0 → F / 60 → D / 70 → C / 80 → B / 90 → A =VLOOKUP(점수, 구간표, 2, TRUE) ' 세율표·할인율표·학점표
⚠ 왼쪽을 못 봄
찾는 열은 반드시 표의 맨 왼쪽, 가져올 값은 그 오른쪽 — 왼쪽이 필요하면 XLOOKUP·INDEX+MATCH
⚠ 표범위는 절대참조
아래로 복사할 거면 $F$2:$H$100 — 안 하면 표가 밀려 내려가며 #N/A
⚠ 열번호는 표 기준
시트의 열이 아니라 지정한 표범위 안에서 몇 번째인지
HLOOKUP

02 XLOOKUP — 현대의 정답 2021 · 365
=XLOOKUP(찾을값, 찾을범위, 가져올범위, [없을때], [일치방식], [검색방향]) =XLOOKUP(A2, F:F, H:H, "없음") ' 열 번호 세기 없음 · 왼쪽/오른쪽 어디든 가능 · 기본이 정확 일치 · 없을 때 값 내장 =XLOOKUP(A2, F:F, D:D) ' 왼쪽 열 가져오기 — VLOOKUP은 불가능 =XLOOKUP(A2, F:F, H:H,, -1) ' -1 = 없으면 작은 값 쪽 근사 (구간표) =XLOOKUP(A2, F:F, H:H,,, -1) ' 검색방향 -1 = 아래→위 (마지막 항목 찾기) ' 이중 XLOOKUP = 행·열 교차값 (2차원 검색) =XLOOKUP(행값, 행머리글, XLOOKUP(열값, 열머리글, 데이터표))
💡 여러 열을 한 번에 가져오려면 가져올범위를 여러 열로 (=XLOOKUP(A2, F:F, G:I) → 3개 셀에 스필). 구버전 엑셀(2019 이하)과 파일을 공유한다면 VLOOKUP을 유지하는 게 안전합니다.
03 INDEX + MATCH — 만능 조합

' 이벤트 — 시트 모듈(프로젝트 창에서 시트 더블클릭)에 작성 Private Sub Worksheet_Change(ByVal Target As Range) If Not Intersect(Target, Range("B:B")) Is Nothing Then Target.Offset(0, 1).Value = Now ' B열 입력 시 C열에 입력시각 자동 기록 End If End Sub ' 사용자 정의 함수(UDF) — 일반 모듈에 Function으로 작성, 시트에서 =수수료(B2) Function 수수료(금액 As Double) As Double If 금액 >= 1000000 Then 수수료 = 금액 * 0.01 Else 수수료 = 금액 * 0.02 End If End Function

실무 단골 수식 모음 · 오류값 사전 · 성능 팁
01 실무 단골 수식 모음
' 누계 (위에서부터 합) — 시작만 고정 =SUM($C$2:C2) ' 아래로 복사 ' 만 나이 / 근속연수 =DATEDIF(생일, TODAY(), "y") ' 주민번호 → 성별 =IF(ISODD(MID(A2,8,1)), "남", "여") ' 이메일 아이디만 추출 =LEFT(A2, FIND("@", A2)-1) ' 두 명단 비교 — B명단에 있는지 =IF(COUNTIF(명단B, A2)>0, "있음", "없음") ' 텍스트로 저장된 숫자 → 숫자 (초록 삼각형 해결) =VALUE(TRIM(A2)) ' 또는 A2*1 · 또는 텍스트 나누기 한 방 ' 조건 순위 — 부서 내 매출 순위 =COUNTIFS($A$2:$A$100,A2, $C$2:$C$100,">"&C2)+1 ' N번째 등장만 표시 (첫 등장만 남기기) =IF(COUNTIF($A$2:A2, A2)=1, "최초", "중복") ' 여러 시트 같은 위치 합계 (3D 참조) =SUM('1월:12월'!B10) ' 1월~12월 시트의 B10 전부
02 오류값 사전 — 뜨는 이유와 해결
#N/A
찾는 값이 없음 (VLOOKUP류)
오타·공백(TRIM)·숫자vs텍스트 불일치 확인 → 정상이면 IFNA로 감싸기
#REF!
참조하던 셀이 삭제됨
행·열 삭제가 원인 — Ctrl+Z, 수식의 #REF! 부분 재지정
#DIV/0!
0 또는 빈 셀로 나눔
=IF(B2=0, "", A2/B2) 또는 IFERROR
#VALUE!
타입이 안 맞음 (숫자 자리에 텍스트)
범위에 문자가 섞였는지 확인 — 눈에 안 보이는 공백이 범인일 때 많음
#NAME?
함수·이름 철자 오류
오타, 또는 구버전에 없는 함수(XLOOKUP을 2016에서) 사용
#SPILL!
스필 결과 자리에 값이 있음
아래·옆 셀 비우기 (동적 배열 함수 전용 오류)
#####
열이 좁음 (오류 아님)
열 경계 더블클릭 = 자동 맞춤. 음수 시간일 때도 발생
순환 참조 경고
수식이 자기 자신을 참조
수식 → 오류 검사 → 순환 참조에서 위치 확인
03 성능 · 관리 팁
열 전체 참조 남용 금지
SUMPRODUCT·배열수식에 A:A를 쓰면 100만 행 전체 계산 — 표(Ctrl+T) 참조나 필요한 범위만
휘발성 함수 주의
NOW·TODAY·OFFSET·INDIRECT·RAND는 모든 편집마다 재계산 — 수천 개 깔리면 파일이 굼떠짐
수식 → 값 고정
확정된 과거 데이터는 복사 → 값만 붙여넣기로 계산 부하 제거
원본·계산·보고서 시트 분리
원본 데이터는 세로 1줄 1건으로(집계는 피벗에 맡기기) — 병합 셀은 원본 시트에서 금지
