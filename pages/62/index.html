🔮 Obsidian이란?
로컬 마크다운 기반 지식 관리 앱 — 노트 간 링크로 두 번째 뇌를 만든다
🧠 핵심 철학
Obsidian은 로컬 마크다운(.md) 파일을 저장소(Vault)로 관리하며, [[내부 링크]]로 노트 간 연결망을 형성합니다. 클라우드가 아닌 내 PC에 데이터가 저장되어 영구적이고 안전합니다. 인터넷 연결 없이도 완전히 작동합니다.
📁로컬 저장 (Vault)
모든 노트는 일반 .md 파일로 컴퓨터에 저장됩니다. 앱이 사라져도 데이터는 내 것. 다른 앱으로 언제든 열람 가능.
🔗양방향 링크
[[노트이름]] 형식으로 노트를 연결하면 자동으로 백링크가 생성됩니다. 아이디어 간 관계망을 시각화합니다.
🕸️그래프 뷰
노트 간 링크를 인터랙티브 그래프로 시각화합니다. 지식 구조를 한눈에 파악하고 고립된 노트를 찾을 수 있습니다.
🧩플러그인 생태계
1,000개 이상의 커뮤니티 플러그인으로 기능을 무한 확장. 캘린더, 칸반, 데이터베이스, AI 연동 등 가능.
🎨테마 & 커스텀
수백 개의 커뮤니티 테마와 CSS Snippet으로 외관을 완전히 커스터마이즈할 수 있습니다.
🆓무료 & 유료 옵션
개인 사용 무료. 유료 서비스: Sync(클라우드 동기화, $8/월), Publish(웹 퍼블리시, $16/월).
⚙️ 기본 개념
🗃️Vault (보관소)
Obsidian이 관리하는 폴더 단위. 한 폴더 = 하나의 Vault. 여러 Vault를 동시에 운영할 수 있으며, 설정과 플러그인은 Vault별로 독립됩니다.
.obsidian 폴더설정 분리복수 운영
📝Note (노트)
개별 .md 파일. 마크다운 문법으로 작성하며 제목, 본문, 태그, 프로퍼티(front matter)를 포함할 수 있습니다.
.md 파일마크다운YAML front matter
🏷️Tags & Properties
#태그 또는 YAML front matter로 노트를 분류합니다. Properties 패널에서 날짜, 상태, 카테고리 등 구조화된 메타데이터를 관리합니다.
#태그YAML메타데이터
🔗Wiki Link
[[노트제목]] 형식으로 다른 노트에 링크. 파이프(|)로 표시 텍스트 변경: [[파일명|보여줄 이름]]. 헤딩 링크: [[파일#헤딩]].
[[링크]]자동완성백링크
📎Embed (포함)
![[파일명]] 으로 다른 노트, 이미지, PDF를 현재 노트 안에 인라인으로 표시합니다. 블록/헤딩 단위 포함도 가능합니다.
![[포함]]이미지PDF
🧱Block Reference
특정 문단/블록에 ^id를 붙이면 다른 노트에서 [[파일^id]] 형식으로 해당 블록만 링크하거나 포함시킬 수 있습니다.
^블록ID세밀한 링크
ℹ️
플랫폼: Windows, macOS, Linux, iOS, Android 지원. 모바일 앱도 전체 기능 사용 가능합니다.
⚡ 핵심 기능 상세
Obsidian이 제공하는 강력한 기능들을 카테고리별로 정리
📝 편집 기능
✏️Live Preview 모드기본
마크다운을 입력하는 즉시 렌더링 결과를 보여주는 편집 모드. 커서가 있는 곳만 원문 표시, 나머지는 미리보기로 보입니다. Ctrl+E로 Reading View 전환.
📖Reading View기본
완전히 렌더링된 읽기 전용 뷰. 편집 불가 상태로 노트를 깔끔하게 읽을 수 있습니다. 우상단 연필 아이콘이나 Ctrl+E로 전환.
🔤Source Mode기본
순수 마크다운 원문 편집기. 렌더링 없이 텍스트 그대로 편집. 고급 사용자나 특수 문자 처리 시 유용합니다. 설정에서 기본 모드 지정 가능.
📐분할 패널기본
화면을 수평/수직으로 분할해 여러 노트를 동시에 볼 수 있습니다. 원문과 미리보기를 나란히 놓거나 두 노트를 비교할 때 유용합니다.
🔤Vim 모드설정
설정 → 편집기 → Vim key bindings 활성화. Vim 단축키로 커서 이동, 편집, 선택 등을 키보드만으로 수행합니다.
🌊Typewriter Scroll플러그인
커서 줄을 항상 화면 중앙에 고정하는 타이프라이터 스크롤. 장문 작성 시 눈의 피로를 줄입니다. 커뮤니티 플러그인으로 추가.
🔍 검색 & 탐색
🔍전체 검색
Vault 내 모든 노트에서 텍스트 검색. 정규식 지원, 태그 검색(tag:#태그), 파일명 검색(file:이름), 경로 검색(path:폴더) 등 연산자 조합 가능.
Ctrl+Shift+F정규식연산자
⚡Quick Switcher
파일 이름으로 빠르게 노트를 열거나 생성하는 팔레트. 입력 즉시 파지 결과를 표시합니다. 존재하지 않는 이름 입력 후 Enter로 새 노트 생성.
Ctrl+O빠른 열기
🎯Command Palette
모든 명령어에 접근하는 팔레트. 플러그인 명령, 설정 열기, 테마 변경 등 GUI 메뉴 없이 키보드로 빠르게 실행합니다.
Ctrl+P모든 명령
🔀Backlinks 패널
현재 노트를 링크하는 모든 노트의 목록. Unlinked mentions(링크 없는 언급)도 보여줍니다. 지식 그물망의 역방향 탐색.
우측 패널역링크
🗂️Outgoing Links
현재 노트에서 링크하는 노트 목록과 아직 생성되지 않은 링크(unresolved)를 보여줍니다.
나가는 링크미해결 링크
📋Outline 패널
현재 노트의 헤딩 목차를 사이드 패널에 표시합니다. 클릭으로 해당 섹션으로 즉시 이동. 긴 문서 탐색에 필수.
목차헤딩 탐색
🕸️ 그래프 & 시각화
🌐Global Graph View
Vault 전체의 노트 링크 관계를 인터랙티브 그래프로 표시. 줌/팬, 필터(태그·폴더·검색), 색상 그룹, 링크 세기 조절 가능. 지식 구조를 시각적으로 파악.
Ctrl+G필터색상 그룹
🔵Local Graph View
현재 열린 노트 중심의 로컬 그래프. 1~6단계까지 깊이 설정으로 관련 노트 범위를 조절합니다.
Ctrl+Shift+G깊이 설정
🎨Canvas
무한 캔버스에 노트 카드, 이미지, 웹 페이지를 자유롭게 배치하고 화살표로 연결하는 시각적 사고 도구. Miro/FigJam 스타일 화이트보드.
무한 캔버스마인드맵.canvas 파일
🔒 동기화 & 보안
☁️Obsidian Sync유료
Obsidian 공식 E2E 암호화 동기화 서비스. 버전 기록 1년, 최대 10GB. 월 $8 또는 연 $48. 가장 안정적이지만 가격이 있음.
📂iCloud / Google Drive 동기화무료
Vault 폴더를 클라우드 드라이브 안에 두면 자동 동기화. 무료지만 모바일 앱과의 동기화 설정이 까다로울 수 있음.
🔑File Recovery
코어 플러그인. 변경 사항을 자동으로 스냅샷 저장(기본 5분 간격, 최대 7일). 실수로 삭제하거나 덮어쓴 내용 복구 가능.
🔌 코어 플러그인 (내장)
설정 → 코어 플러그인에서 각각 활성화/비활성화 가능. 기본 설치되어 있는 공식 플러그인들.
✅
코어 플러그인은 Obsidian 팀이 직접 개발·유지합니다. 안정성이 보장되며 업데이트 시 함께 갱신됩니다.
🔗Backlinks
현재 노트를 참조하는 모든 노트 목록 표시. 링크되지 않은 언급(Unlinked mentions)도 탐지합니다. 사이드 패널 또는 노트 하단에 표시.
🎨Canvas
무한 캔버스 화이트보드. .canvas 파일 형식으로 저장되며 노트 임베드, 이미지, 링크, 자유 그리기 지원.
⌨️Command Palette
Ctrl+P로 열리는 명령어 팔레트. 모든 플러그인 명령에 빠르게 접근. 최근 사용 명령 상단 표시, 핀 고정 기능.
📅Daily Notes
오늘 날짜 노트를 자동 생성. 날짜 형식, 저장 폴더, 템플릿 파일 설정 가능. Ctrl+Shift+D로 바로 열기.
📁File Explorer
Vault의 폴더·파일 트리 탐색기. 새 파일/폴더 생성, 이동, 이름 변경, 드래그&드롭 지원.
💾File Recovery
편집 내역을 주기적으로 스냅샷 저장. 실수로 내용을 삭제했을 때 이전 버전 복구 가능. 보존 기간과 간격 설정 가능.
🕸️Graph View
노트 링크 관계 시각화. 전체/로컬 그래프 모두 지원. 필터, 색상 그룹, 물리 시뮬레이션 설정 가능.
🔵Note Composer
현재 노트의 일부를 새 노트로 분리하거나, 반대로 다른 노트를 현재 노트에 합칩니다. 노트 재구성 시 유용.
🔗Outgoing Links
현재 노트가 링크하는 노트와 미해결 링크 목록. 존재하지 않는 링크를 클릭하면 새 노트 생성.
📋Outline
현재 노트의 헤딩 목차를 사이드 패널에 표시. 헤딩 클릭으로 즉시 이동. 긴 문서 탐색에 필수적.
👀Page Preview
링크 위에 마우스를 올리면 해당 노트 내용을 팝업으로 미리 봅니다. 링크를 열지 않고 내용 확인 가능.
🗂️Properties
노트의 YAML front matter를 UI로 편집. 필드 타입(텍스트, 날짜, 숫자, 체크박스, 리스트, 링크) 지원. 노트 메타데이터 관리 핵심.
⚡Quick Switcher
Ctrl+O로 노트 이름 검색 후 즉시 이동. 없는 이름 입력 후 Enter로 새 노트 생성. 키보드 중심 워크플로의 핵심.
🎲Random Note
Vault에서 무작위로 노트를 엽니다. 잊혀진 오래된 노트를 다시 발견하거나 복습할 때 활용.
🔍Search
Vault 전체 텍스트 검색. tag:, file:, path:, line:, block: 등 다양한 검색 연산자. 결과를 파일로 저장하는 Copy Results 기능.
/Slash Commands
편집기에서 / 입력 시 삽입 명령 목록 표시. 날짜 삽입, 템플릿 적용, 콜아웃 삽입 등을 마우스 없이 실행.
📊Slides
--- 구분선으로 슬라이드를 나누어 프레젠테이션 모드로 보기. 간단한 발표 자료 제작에 활용.
🏷️Tags View
Vault의 모든 태그와 사용 빈도를 목록으로 표시. 태그 클릭으로 해당 태그를 가진 노트만 검색.
📄Templates
지정한 폴더의 노트를 템플릿으로 사용. {{date}}, {{time}}, {{title}} 변수 지원. Ctrl+Shift+T로 현재 노트에 삽입.
🆔Unique Note Creator
Zettelkasten 스타일의 고유 ID(타임스탬프) 노트 생성. 날짜/시간 기반 파일명으로 노트 충돌 방지.
📊Word Count
편집기 하단 상태바에 단어 수, 문자 수 표시. 현재 선택 영역 기준 카운트도 실시간으로 반영.
🌐Publish유료
선택한 노트를 obsidian.md 도메인 웹사이트로 공개 퍼블리시. 월 $16. 그래프 뷰, 검색, 커스텀 도메인 지원.
☁️Sync유료
Obsidian 공식 E2E 암호화 동기화. 버전 기록, 선택적 동기화, 최대 10GB. 월 $8. 가장 안정적인 동기화 방법.
🌐 커뮤니티 플러그인 (인기 TOP)
설정 → 커뮤니티 플러그인 → 찾아보기에서 설치. 1,000개 이상 존재.
⚠️
주의: 커뮤니티 플러그인은 서드파티 개발자 작성. 설치 전 제한 모드 비활성화 필요. 신뢰할 수 있는 플러그인만 설치 권장.
📊 데이터 & 쿼리
⭐ 필수
Dataview
노트 메타데이터를 SQL 유사 언어로 쿼리하여 테이블·목록·캘린더 뷰로 표시. 동적 대시보드 제작의 핵심.
예: 이번 주 작성한 모든 #프로젝트 노트 목록 자동 생성
⭐ 인기
DB Folder
폴더를 Notion 스타일 데이터베이스로 변환. 인라인 편집, 필터, 정렬, 속성 관리 가능.
예: 독서 목록, 영화 리뷰, 레시피 관리
📝 템플릿 & 자동화
⭐ 필수
Templater
코어 Templates보다 강력한 템플릿 엔진. JavaScript 실행, 날짜 계산, 사용자 입력 받기, 파일 이동 등 고급 자동화.
예: 회의록 자동 날짜 삽입, 제목 기반 파일 이동
⭐ 인기
QuickAdd
빠른 노트 추가, 템플릿 실행, 매크로 등록을 단축키로 연결. 캡처·처리 워크플로를 단순화.
예: 단축키 하나로 읽은 책 항목 입력 + 템플릿 적용
📅 시간 관리
⭐ 필수
Calendar
사이드 패널에 달력 표시. 날짜 클릭으로 데일리 노트 열기/생성. 주간·월간 뷰 지원.
데일리 노트 연동 필수 플러그인
⭐ 인기
Periodic Notes
데일리 외 위클리(주간), 먼슬리(월간), 쿼터리(분기), 이어리(연간) 노트 자동 생성. Zettelkasten 계획 관리.
주간 리뷰, 월간 목표 관리
Tasks
Vault 전체의 태스크를 쿼리하여 통합 할 일 목록 생성. 마감일, 반복, 우선순위, 완료 처리 지원.

📁 PARA 폴더 구조 (Tiago Forte)
Projects (프로젝트) — 현재 진행 중인 목표 기한 있는 작업

Resources (자원) — 관심 주제, 참고 자료, 나중에 쓸 정보
Archives (아카이브) — 완료됐거나 비활성화된 모든 것
🗃️ Zettelkasten 방법론
1
Fleeting Note — 떠오르는 생각을 즉시 캡처. 임시 메모, 나중에 정리.
2
Literature Note — 책·아티클 내용 요약. 자기 말로 바꿔 기록.
3
Permanent Note — 하나의 아이디어만 담은 원자적 노트. 독립적으로 의미를 가져야 함.
4
Index Note — 관련 노트들을 모아주는 목차 노트. MOC(Map of Content) 라고도 함.
💡Zettelkasten 핵심 원칙
  • 노트 하나에 아이디어 하나만 — 원자성(Atomicity)
  • 복사가 아닌 자기 말로 재구성 — 이해한 것만 기록
  • 노트 간 링크를 적극적으로 생성 — 지식망 형성
  • 폴더보다 링크와 태그로 구조화
  • 노트 파일명은 타임스탬프나 간결한 제목 권장

🔄Dataview 활용 예시
코드 블록에 dataview 언어 지정 후 쿼리 작성:
  • TABLE file.mtime FROM #독서 — 독서 노트 최근 수정순 목록

  • CALENDAR file.ctime — 노트 생성 달력
  • TASK FROM #할일 WHERE !completed — 미완료 작업

🛠️ 자주 묻는 설정
📁 새 노트의 저장 위치를 지정하고 싶어요 ›
설정 → 파일 및 링크 → 새 노트의 위치 → "지정한 폴더"로 선택 후 폴더 경로 입력. Inbox 폴더를 지정해두면 모든 새 노트가 거기에 모입니다.
🔗 링크 형식을 짧게 바꾸고 싶어요 (상대경로 → 파일명만) ›
설정 → 파일 및 링크 → 새 링크 형식 → "최단 경로"로 설정. [[폴더/파일]] 대신 [[파일]]만 표시됩니다.
🎨 다크/라이트 테마를 바꾸고 싶어요 ›
설정 → 테마 → 외관 → 기본 색상 구성 또는 커뮤니티 테마 찾아보기. 인기 테마: Minimal, Things, Prism, Catppuccin, AnuPpuccin.
📝 기본 편집기 폰트를 바꾸고 싶어요 ›
설정 → 테마 → 텍스트 폰트 / 모노스페이스 폰트에서 시스템에 설치된 폰트명 직접 입력. 한글 폰트: 맑은 고딕, 나눔고딕, Pretendard 등.
⚡ 시작 시 자동으로 데일리 노트를 열고 싶어요 ›
코어 플러그인 → Daily Notes → 시작 시 자동으로 열기 체크. Obsidian 실행 시 오늘 데일리 노트가 자동으로 열립니다.
