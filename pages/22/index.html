🚀 GitHub 주요 기능
GitHub에서 제공하는 기능들 개요
📁
Repository
프로젝트의 코드·파일·이슈·PR이 모이는 공간. Public / Private 설정 가능. Fork로 복제해 수정 후 PR 제출.
🐛
Issues
버그 리포트, 기능 요청, 할 일 관리. 레이블·마일스톤·담당자 할당, 템플릿 설정, 타임라인 추적.
🔀
Pull Request
브랜치의 변경사항을 메인 브랜치에 병합 요청. 코드 리뷰, 댓글, 승인(Approve) / 변경 요청(Request changes).
⚙️
Actions
CI/CD 자동화. push·PR·스케줄 등 이벤트에 워크플로우 실행. 빌드·테스트·배포 자동화. YAML 파일로 정의.
📋
Projects
칸반 보드·테이블·로드맵 형태의 프로젝트 관리 도구. 이슈와 PR을 연동해 진행 상황 시각화.
📖
Wiki
저장소별 마크다운 문서 공간. README만으로 부족한 긴 문서, 가이드, 설계 문서 작성.
💬
Discussions
포럼형 커뮤니티 공간. Q&A, 아이디어, 공지 카테고리. 이슈와 달리 느슨한 대화 목적.
📦
Packages
npm·Docker·Maven 등 패키지 레지스트리. 코드와 같은 위치에서 패키지 게시·버전 관리.
🌐
Pages
저장소에서 정적 사이트를 무료로 호스팅. username.github.io/repo 주소로 배포. Jekyll 또는 순수 HTML.
🔒
Security
Dependabot(의존성 취약점 자동 PR), Code scanning(CodeQL), Secret scanning(민감 정보 감지).
📊
Insights
저장소 통계 — 기여자 현황, 커밋 빈도, 코드 변경량, 트래픽, 포크·스타 추이 차트.
🏷️
Releases
태그 기반 버전 릴리스. 바이너리 첨부 가능. 자동 생성 릴리스 노트. GitHub Actions로 자동 배포 트리거.
💻
Codespaces
브라우저·VS Code에서 클라우드 개발환경 즉시 실행. devcontainer.json으로 환경 정의. 무료 월 60시간.
🤖
Copilot
AI 코드 자동완성·채팅·PR 리뷰. IDE 플러그인, GitHub.com 내 채팅, CLI 지원. 유료(개인 $10/월).
🔱
Fork & Star
Fork: 저장소 복제해 독립적으로 수정. Star: 북마크·관심 표시. Watching: 알림 레벨 설정.
🛡️
Branch Protection
main 브랜치 직접 push 차단, PR 필수, 승인 인원 설정, CI 통과 필수, 서명 커밋 요구 등 규칙 설정.

🔄 GitHub 워크플로우
팀 협업과 배포에서 자주 쓰이는 흐름 정리
📌 GitHub Flow (기본 브랜치 전략)
main
→
feature 브랜치
생성
→
커밋 & 푸시
→
PR 생성
→
코드 리뷰
& 승인
→
main 병합
& 배포
1. 브랜치 생성git checkout -b feature/기능명 — main에서 바로 분기
2. 작업 & 커밋작은 단위로 자주 커밋. 커밋 메시지는 feat: ..., fix: ... 형태 권장
3. PR 생성GitHub에서 Pull Request 생성. 제목·설명·리뷰어 지정
4. 리뷰리뷰어가 코드 리뷰 → Approve 또는 Request changes
5. 병합Merge / Squash merge / Rebase merge 선택 후 병합
6. 브랜치 삭제병합 후 feature 브랜치 삭제 (GitHub에서 버튼 제공)
🔀 병합 전략 비교
Merge commit 모든 커밋 보존 + 병합 커밋 추가. 히스토리 그대로 보존. 기본값.
Squash merge PR의 모든 커밋을 하나로 압축. main 히스토리가 깔끔해짐.
Rebase merge 커밋을 main 뒤에 재정렬. 선형 히스토리. 병합 커밋 없음.
⚙️ Actions 워크플로우 기본 구조
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
      - run: npm test
🏷️ 커밋 메시지 컨벤션 (Conventional Commits)
feat: 새 기능
fix: 버그 수정
docs: 문서 수정
refactor: 리팩토링
chore: 빌드/설정
test: 테스트 추가
style: 포맷/공백
revert: 되돌리기
perf: 성능 개선
ci: CI 설정
형식타입(스코프): 제목 — 예) feat(auth): 소셜 로그인 추가
Breaking changefeat!: 기존 API 제거 또는 본문에 BREAKING CHANGE: 기재
자동 버전 범프fix → patch, feat → minor, BREAKING CHANGE → major (semver)
