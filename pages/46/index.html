⛏ Axiom 완전 정복 Minecraft World Editor Mod by Moulberry

Axiom은 Moulberry가 제작한 마인크래프트 Java Edition용 올인원 월드 편집 모드입니다. 전문 3D 소프트웨어 수준의 도구를 브라우저 없이 게임 안에서 실시간으로 사용합니다. Fabric 모드로더 전용이며 1.20.4 ~ 1.21.x를 지원합니다.
모드 개요
🎮 두 가지 모드
🟡 빌더 모드 (Builder Mode)

크리에이티브 기본 기능을 강화한 모드. 직관적 도구로 구조물·소규모 건축에 최적화. Left Alt로 접근.

🔴 에디터 모드 (Editor Mode)

대규모 지형 조각·페인팅·선택·조작을 위한 고급 모드. Right Shift로 접근.

선택 도구 (Selection Tools)
📦 Box Selection (박스 선택)
두 꼭짓점을 지정해 직육면체 영역 선택. 가장 기본적인 선택 도구.
에디터 도구
✏ Freehand Selection (자유형 선택)
마우스로 자유롭게 드래그하여 불규칙한 형태 선택.
에디터 도구
🪄 Magic Selection (매직 선택)
클릭한 블록과 연결된 동일 종류 블록을 자동 선택. 특정 지형 부위 한 번에 선택할 때 유용.
에디터 도구
🔗 Lasso Selection (올가미 선택)
자유형 경로로 영역의 윤곽을 그려 내부 선택.
에디터 도구
드로잉·조각 도구 (Drawing / Sculpt Tools)
✏ Freehand Draw (자유 드로우)
브러시로 자유롭게 블록을 배치. 브러시 크기·모양 조절 가능.
드로잉
🗿 Sculpt Draw (조각)
지형을 점토처럼 조각. 볼륨 추가/제거로 유기적 형태 제작. 산·언덕·절벽 등 자연 지형에 핵심 도구.
드로잉
🪨 Rock Tool (바위)
지형 표면에 울퉁불퉁한 바위 질감 추가. 자연스러운 암벽·절벽 표현.
드로잉
🔗 Weld Tool (용접)
새로운 형태를 기존 지형에 틈새 없이 자연스럽게 합체.
드로잉
🫠 Melt Tool (녹임)
블록을 녹이듯 부드럽게 제거하거나 깎아냄. Sculpt와 반대 방향으로 지형 가공.
드로잉
🖼 Stamp Tool (스탬프)
저장된 블루프린트를 브러시처럼 반복 스탬핑. 회전·스케일 옵션 포함. 나무·바위·장식물 반복 배치에 최적.
드로잉
🔤 Text Tool (텍스트)
블록으로 텍스트를 렌더링. 폰트·크기·방향 설정 가능. 대형 간판, 맵 제목 제작.
드로잉
🔷 Shape / Geometry (도형)
구·원기둥·원환체(토러스) 등 기하학적 도형 생성. 크기·재질·방향 설정. 탑·돔·아치 빠른 제작.
드로잉
〰 Path Tool (경로)
경로를 따라 블록 배치. 강·도로·담장 등 곡선 구조물 제작.
드로잉
🎨 Modeling Tool (모델링)
경로를 따라 표면을 생성하는 로프트(Loft) 방식. 차량·건축물 등 복잡한 형태 제작에 활용.
드로잉
페인팅 도구 (Painting Tools)
🖌 Painter (페인터)
현재 선택 블록 또는 클립보드 패턴으로 블록을 페인팅. 실시간 미리보기 제공.
페인팅
🌊 Noise Painter (노이즈 페인터)
펄린 노이즈 등 절차적 노이즈를 적용해 자연스러운 패턴 생성. 자연 지형의 블록 다양성 표현.
페인팅
🌿 Biome Painter (바이옴 페인터)
3D 공간에 바이옴을 직접 페인팅. 특정 영역의 식물·날씨·하늘 색상 변경.
페인팅
📜 Script Brush (스크립트 브러시)
LIS(Lightweight Interactive Scripting) 코드로 완전 커스텀 브러시 제작. 루프·조건문·블록 조작으로 고급 패턴 생성.
place_block(x, y, z, "stone")
place_block(x, y+1, z, "grass_block")
페인팅 고급
🌈 Gradient Painter (그래디언트)
두 블록 유형 사이를 거리·높이 기준으로 부드럽게 블렌딩. 자연스러운 지형 색상 전환.
페인팅
조작·변형 도구 (Manipulation Tools)
〰 Smooth (스무스)
거친 지형을 부드럽게 평활화. 산·언덕 제작 후 마무리 작업에 필수. 브러시 크기·강도 조절.
조작
🌀 Distort (왜곡)
지형을 임의적으로 왜곡·비틀기. 의도적인 불규칙성 표현.
조작
🪨 Roughen (거칠게)
지형 표면을 거칠게 만들어 자연스러운 질감 추가. Smooth의 반대 효과.
조작
💥 Shatter / Crack (산산조각)
표면에 균열·파편 효과 생성. 폐허·전쟁터 등 파괴된 느낌 표현.
조작
🏔 Heightmap Tools (높이맵)
World Machine·World Painter 방식처럼 2D 높이맵으로 지형 올리기/낮추기. Height 브러시와 Slope(경사) 도구 포함.
조작
💧 Flood Fill / Fluid Ball
Flood Fill: 물·용암의 유체 물리 시뮬레이션으로 영역 채우기.
Fluid Ball: 구형 유체 소스 생성, 확산 범위 조절 가능.
유체
기타 도구
📏 Ruler Tool (자)
두 점 사이 거리 측정. 중점(Midpoint) 자동 계산. 건축 비율 맞추기에 활용.
공통
📌 Annotation Tool (주석)
월드 내에 그림·텍스트·이미지 참조 배치. 협업 시 위치 메모, 설계 레퍼런스 표시.
공통
🎯 Gizmo (기즈모)
선택 영역이나 클립보드 오브젝트를 3D 핸들로 이동·회전·스케일. 정밀 배치에 활용.
에디터

블루프린트 시스템
💾 블루프린트 저장
선택 영역을 클립보드에 복사 후 Blueprint Browser에서 저장. .bp 파일로 로컬 저장.
영역 선택 → Ctrl+C
Blueprint Browser 열기 (Windows → Blueprint Browser)
'Save' 버튼으로 .bp 파일로 저장
📥 블루프린트 불러오기 & 배치
썸네일 클릭 → 클립보드 로드 → Ctrl+V로 배치. 기즈모로 회전·이동 후 Enter로 확정.
🤝 블루프린트 공유
.bp 파일을 다른 사용자와 공유. 상대방의 .minecraft/config/axiom/blueprints 폴더에 배치하면 즉시 사용 가능.
🎨 BDEngine 연동
BDEngine에서 제작한 Display Entity 모델을 Axiom 명령어로 붙여넣기 가능. BDEngine 카탈로그에서 Axiom용 명령어 복사 → 마인크래프트에서 Ctrl+V.

지형·테라포밍 응용

🏔 자연 산악 지형 제작

목표: 마인크래프트 느낌의 거친 암산 제작
  1. 에디터 모드(Right Shift) 진입
  2. Sculpt Draw로 기본 산 형태 구성 (볼륨 추가/제거)
  3. Rock Tool로 절벽면에 바위 질감 추가
  4. Smooth로 지나치게 거친 부분 부드럽게 처리
  5. Roughen으로 산 능선에 자연스러운 불규칙성 추가
  6. Noise Painter로 돌·흙·잔디 블록 자연스럽게 혼합

🌊 강 & 호수 지형 제작

목표: 자연스러운 강줄기와 호수
  1. Path Tool로 강줄기 경로 설정
  2. Sculpt Draw로 강바닥 파기
  3. Smooth로 강 경계 자연스럽게 처리
  4. Flood Fill로 물 채우기
  5. Biome Painter로 강 주변 바이옴 설정

🌿 자연 식생 분산

목표: 나무·바위·식물을 자연스럽게 분산
  1. 나무 구조물을 블루프린트로 저장
  2. Stamp Tool에 나무 블루프린트 로드
  3. Noise Painter와 조합해 무작위 위치에 나무 스탬핑
  4. Tool Mask로 잔디 블록 위에만 적용되도록 필터
건축·구조물 응용

🏰 대칭 성 제작

목표: 좌우 완전 대칭 성 효율적으로 건축
  1. 빌더 모드에서 Setup Symmetry 도구로 중심점 설정
  2. 한쪽만 건축하면 반대쪽 자동 미러링
  3. 탑·망루는 Shape Tool(원기둥)으로 빠르게 생성
  4. Extrude로 성벽 두께 조절
  5. 완성된 탑을 블루프린트 저장 후 Stamp로 반복 배치

🏙 대형 도시 건설

목표: 블록 수백만 규모의 도시
  1. 건물 유닛 제작 후 블루프린트 저장
  2. Stack Tool로 건물 층수 빠르게 쌓기
  3. Clone Tool로 동일 건물 여러 위치에 배치
  4. 도로는 Path Tool로 생성
  5. Ctrl+F로 대규모 지면 정리

🎨 블록 아트 & 픽셀 아트

목표: 대형 벽면 블록 아트 제작
  1. Text Tool로 텍스트 레이아웃 확인
  2. Gradient Painter로 색상 전환 표현
  3. Noise Painter로 질감 다양화
  4. 블루프린트로 저장해 다른 맵에서 재사용
고급 응용

📜 Script Brush 응용 (LIS 스크립팅)

목표: 반복 패턴을 코드로 자동 생성
  1. Tool Options → Script Brush 선택
  2. Lua 코드 에디터에 규칙 작성
  3. 예: 3블록마다 다른 재질 배치, 높이에 따른 블록 변경
  4. 미리보기 확인 후 적용
-- 높이에 따라 다른 블록 배치
if y < 60 then
  place_block(x, y, z, "stone")
elseif y < 70 then
  place_block(x, y, z, "dirt")
else
  place_block(x, y, z, "grass_block")
end

🎭 Tool Mask 활용

목표: 특정 블록에만 선택적으로 도구 적용
  1. Windows → Tool Masks 패널 열기
  2. 적용할 블록 종류 또는 조건 설정
  3. 예: 잔디 블록 위에만 나무 스탬프 배치
  4. 예: Y=60 이하 블록에만 페인터 적용
  5. 복잡한 조건은 Lua 스크립트로 작성

🤝 BDEngine + Axiom 연동

목표: BDEngine 모델을 맵에 빠르게 삽입
  1. BDEngine(bdengine.app)에서 Display Entity 모델 제작
  2. 카탈로그에 게시 또는 직접 Export → Axiom 명령어 복사
  3. 마인크래프트에서 에디터 모드 진입
  4. Ctrl+V로 붙여넣기 → 기즈모로 위치 조정
  5. Enter로 확정

필수 팁 & 트릭
⚡ 생산성 팁
💡슬라이더 Ctrl+클릭제한 수치 초과해서 입력 가능. 브러시 크기 수백 블록으로 키울 수 있음
💡Tool Presets자주 쓰는 도구 세팅을 프리셋으로 저장. 세팅마다 이름 부여 가능
💡블록 이름 타이핑핫바 검색창에 블록 이름 타이핑 후 Enter → 즉시 핫바에 추가
💡비행 속도하단 슬라이더로 즉시 조절. 대형 맵에서 10배 속도로 빠른 이동
💡텍스트 박스 수식좌표 입력란에 sin(45)*100 같은 수식 계산 입력 가능
🎯 지형 제작 팁
🏔Sculpt → Smooth먼저 Sculpt로 대략적인 형태 잡고, Smooth로 마무리하는 게 자연스러움
🪨Rock 마무리절벽·암벽에 Rock Tool 마지막에 살짝 적용하면 현실감 급상승
🌊Heightmap 활용World Painter에서 내보낸 높이맵 이미지를 Axiom Heightmap Tool로 불러올 수 있음
🎨Noise 레이어링Noise Painter를 여러 번 겹쳐 적용하면 더 복잡한 자연 패턴 생성
