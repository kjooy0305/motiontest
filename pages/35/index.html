디오니소스의 스승 실레노스를 호대접 → 소원 한 가지 허락 → "손에 닿는 모든 것이 황금이 되길" → 음식·물·딸까지 황금으로 변해 비극 → 소원 취소 간청 → 팍톨로스 강에 씻어 황금손 사라짐. 이후 판vs아폴론 음악 대결에서 판 편 → 아폴론이 당나귀 귀로 변신.
🌹 에로스와 프시케
사랑·호기심·구원의 신화
인간 공주 프시케의 아름다움이 아프로디테를 능가 → 아프로디테가 에로스에게 저주 명령 → 에로스가 프시케에게 반함 → 비밀 결혼(어둠 속, 얼굴 불가) → 언니들의 꼬드김 → 촛불로 에로스 확인 → 에로스 상처·도주 → 아프로디테의 4가지 시련(씨 분류·황금 양털·저승 물·아름다움 상자) → 프시케 극복 → 에로스 구출 → 제우스 승인으로 불사 획득·결혼.
🏛️ 시시포스의 형벌
헛된 노동·부조리의 상징
교활한 왕 시시포스가 죽음의 신 타나토스를 쇠사슬로 묶어 한동안 세상에 죽음이 없었음 → 제우스 개입·해방 → 다시 한 번 아내에게 장례 없이 보내달라 부탁 → 하데스에게 "잠시 지상에 다녀오겠다" 거짓말 → 탈출 성공 · 결국 붙잡혀 영원한 형벌: 거대한 바위를 산 정상까지 밀어올리면 굴러 내려옴 — 영원 반복.
🌺 히아킨토스의 죽음
히아신스꽃의 기원
아폴론이 사랑한 미소년 히아킨토스 → 원반던지기 중 서풍의 신 제피로스가 질투로 바람을 바꿈 → 원반이 히아킨토스 머리를 강타 → 사망 → 피에서 히아신스꽃 피어남 → 꽃잎에 "Ai Ai"(슬픔의 외침) 문양.
🦅 이카로스의 비행
오만과 추락의 경고
발명가 다이달로스가 크레타에 감금 → 밀랍 날개 제작 → 아들 이카로스에게 "너무 낮으면 파도에 젖고, 너무 높으면 태양에 녹는다" 경고 → 이카로스가 흥분하여 너무 높이 날아오름 → 밀랍 녹아 추락·익사 → 이카리아 해 유래. 다이달로스는 시칠리아로 안전하게 탈출.
🕸️ 아라크네의 오만
거미의 기원
직녀 아라크네가 "아테나보다 베를 잘 짠다"고 자랑 → 아테나가 노파로 변장해 경고 → 무시 → 대결: 아라크네의 직물에 신들의 불륜·비행이 완벽히 수놓임 → 아테나 분노 → 아라크네의 직물을 찢고 저주 → 아라크네 자살 → 아테나가 불쌍히 여겨 거미로 변신 → 영원히 실을 짬.
