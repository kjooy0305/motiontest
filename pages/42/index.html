컨텍스트 변경 후 명령어 실행. 데이터팩 핵심 명령어
/execute as @a run say 안녕!
/execute at @p run setblock ~ ~-1 ~ stone
/execute as @a at @s run kill @e[type=arrow,distance=..2]
/execute if block ~ ~-1 ~ grass_block run say 잔디 위에 있음
/execute unless entity @e[tag=boss] run say 보스 없음
/execute if score @p kills matches 10.. run say 10킬 달성!
/execute store result score @p result run data get entity @p Health

OP
선택자 (@a @p @e @r @s)
기본 선택자
대상 지정 특수 문자
@p가장 가까운 플레이어
@a모든 플레이어
@e모든 엔티티
@r무작위 플레이어
@s명령어 실행 주체
@n가장 가까운 엔티티(1.21.4+)
선택자 인수 목록
[ ] 안에 조건 입력, 쉼표로 AND 결합
type=zombie엔티티 종류
type=!player종류 제외
name="이름"이름 일치
distance=..55블록 이내
distance=5..105~10블록
limit=1최대 1개
sort=nearest가까운 순
sort=farthest먼 순
sort=random무작위 순
sort=arbitrary임의 순서
x= y= z=중심 좌표
dx= dy= dz=범위 크기
gamemode=creative게임모드
level=10..20경험치 레벨 범위
tag=tagname태그 보유
tag=!tagname태그 미보유
team=red팀 소속
scores={kills=10..}점수판 조건
nbt={IsBaby:1b}NBT 조건
predicate=...조건 파일
advancements={...}발전 달성 여부
좌표 표기법
명령어에서 위치를 지정하는 방법
~ ~ ~실행자 상대 좌표
~5 ~1 ~-3상대 오프셋
^ ^ ^실행자 시선 기준 로컬 좌표
^1 ^ ^오른쪽 1블록
^ ^1 ^위 1블록
^ ^ ^1앞 1블록
10 64 -5절대 좌표
