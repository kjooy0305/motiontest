🎵 Incredibox — 소리로 만드는 애니메이션
캐릭터에 아이콘을 입혀 비트·이펙트·멜로디·보이스·코러스를 쌓으면 음악이 만들어집니다. 조합이 맞으면 보너스 애니메이션이 터집니다.

개발사So Far So Good — 프랑스 낭트 소재 소규모 스튜디오. 아티스트 Allan Durand가 2009년 혼자 시작한 프로젝트.

언어 지원UI가 거의 없어서 언어 장벽 없음. 전 세계 누구나 바로 플레이.

🎮게임의 핵심 구조
드래그 앤 드롭 하나로 끝. 소리 아이콘을 캐릭터에 올리면 음악이 시작되고, 빼면 멈춥니다. 악기를 다룰 줄 몰라도 됩니다.
  • 화면에 7명의 캐릭터가 서 있고, 각각 하나의 악기/사운드를 담당합니다.
  • 상단에 아이콘 팔레트가 있고, 아이콘마다 소리가 지정되어 있습니다.
  • 아이콘을 캐릭터 위로 드래그하면 해당 캐릭터가 소리를 냅니다.
  • 모든 소리는 자동으로 박자에 맞게 루프됩니다 — 타이밍 신경 쓸 필요 없음.
  • 특정 조합이 맞으면 캐릭터들이 갑자기 보너스 애니메이션을 수행합니다.
🏆왜 이 게임이 유명한가
  • 진입 장벽 제로. 클릭 한 번으로 바로 그럴듯한 음악이 만들어집니다.
  • 숨겨진 보너스 시스템. 조합을 발견하는 재미가 중독적입니다.
  • 공유·랭킹. 만든 믹스를 저장하고 URL로 공유할 수 있습니다. 사이트에서 다른 사람 믹스를 듣고 평가할 수 있습니다.
  • 팬 창작물 폭발. Sprunki를 비롯한 수십 개의 팬메이드 버전이 생겨 2024년에 다시 폭발적으로 화제가 됐습니다.
  • 음악 교육 도구로 활용. 세계 각지 학교에서 리듬·화음 교육에 사용합니다.
🆚웹 vs 모바일 vs Steam — 뭐가 다른가
플랫폼차이
웹 (무료)incredibox.com에서 체험. v1 Alpha만 무료. 나머지는 잠금. 회원가입 없이 바로 시작.
모바일 앱유료 앱. 터치로 드래그. 여러 버전 선택 가능. 개인 취향에 따라 PC보다 조작감 좋을 수도.
Steam 권장한 번 구매로 모든 버전 포함. 마우스 조작이 제일 편함. 스팀 도전과제 있음. 업데이트 자동.

🖱️기본 조작법
아이콘 올리기상단 팔레트에서 아이콘을 드래그해 캐릭터 위로 끌어놓으면 해당 소리 활성화.
아이콘 빼기캐릭터를 클릭하거나 아이콘을 팔레트로 다시 드래그하면 소리 제거.
믹스 저장화면 하단 Save/Record 버튼. 링크·코드가 생성되어 공유 가능.
다른 믹스 듣기Community/Chart 탭에서 다른 사용자 믹스 감상 및 좋아요.
버전 변경메인 메뉴에서 원하는 앨범 선택. 사운드 세트가 완전히 교체됩니다.
녹음Record 버튼으로 오디오 녹음 후 MP3로 내보내기 가능 (버전별로 다름).
💡보기 좋은 믹스를 만드는 순서
  • 1단계 — Beat 먼저. 드럼·베이스 리듬 1~2개를 올려 박자를 잡습니다.
  • 2단계 — Effect 추가. 리듬에 타악기 텍스처를 더합니다. 너무 많으면 복잡해집니다.
  • 3단계 — Melody 올리기. 악기 선율을 하나 올립니다. 두 개 이상은 화음이 충돌할 수 있습니다.
  • 4단계 — Voice / Chorus. 보컬을 마지막에 올리면 자연스럽게 클라이맥스가 됩니다.
  • 7명 모두 채울 필요 없습니다. 4~5명 정도가 오히려 더 깔끔하게 들리는 경우가 많습니다.
  • 보너스가 터지면 잠깐 기다리세요. 애니메이션 중에도 루프는 계속 돌고 있습니다.
흔한 실수 — 7명 전부 Beat로 채우기. 소리가 뭉개져서 박자를 알아들을 수 없게 됩니다. 타입을 골고루 섞어야 풍성해집니다.
🎯보너스 애니메이션 발동 조건
  • 각 버전마다 숨겨진 조합이 3~5개 있습니다. 특정 아이콘들을 동시에 활성화하면 발동합니다.
  • 보너스는 에픽·중간·소소 등 규모가 다릅니다. 대형 보너스는 캐릭터 전체가 군무를 춥니다.
  • 조합을 직접 발견하는 재미가 핵심 — 처음에는 힌트 없이 이것저것 올려보는 게 좋습니다.
  • 공식 사이트·팬 위키에 조합표가 공개되어 있습니다. 스포일러 주의.
  • 보너스는 아이콘이 정해진 슬롯(캐릭터)에 상관없이 종류만 맞으면 발동합니다.

⚡보너스 발동 기본 원리
  • 각 버전에 3~5개의 숨겨진 조합이 있습니다.
  • 특정 아이콘 타입들을 동시에 활성화하면 발동. 어느 캐릭터에 올리는지는 무관합니다.
  • 보너스가 터지면 음악이 잠시 멈추고 특별 애니메이션이 재생된 뒤 원래 믹스로 돌아옵니다.
  • 여러 보너스를 동시에 활성화하면 중첩되지 않고, 조건이 맞는 것만 순차 발동합니다.
  • 보너스를 모두 발견하면 각 버전의 완료 배지를 얻을 수 있습니다.
발견 전략 — 아이콘을 3~4개씩 바꿔가며 올려보세요. 보너스가 터지면 어떤 조합이었는지 기억해 두고, 그 아이콘들을 남겨두고 나머지를 바꾸면 됩니다.
🎵Alpha — 보너스 조합 (v1)
스포일러 포함. 직접 찾는 재미를 원하면 건너뛰세요.
보너스조합 설명애니메이션
보너스 A Beat 3번 + Voice 1번 (빨간 계열 아이콘 조합) 캐릭터들이 하늘로 뛰어오름
보너스 B Effect 3번 + Melody 1번 (주황 계열 위주) 비가 내리는 배경 애니메이션
보너스 C Beat + Effect + Melody + Voice + Chorus 각 1개씩 — 5타입 전부 가장 화려한 풀 앙상블 퍼레이드
정확한 아이콘 번호는 버전 업데이트로 바뀔 수 있습니다. 팬 위키(Incredibox Wiki)에서 최신 조합표를 확인하세요.
🎚️더 좋은 믹스 만드는 팁 10가지
  • Beat를 홀수로. 2개보다 1개 또는 3개가 리듬이 더 선명합니다.
  • Melody는 1개만. 2개 이상이면 조성이 충돌해 불협화음이 됩니다.
  • 빈 슬롯을 두세요. 7명 다 채우는 것보다 5명이 더 깔끔한 경우가 많습니다.
  • Effect로 레이어를 쌓으세요. 단순한 Beat 위에 Effect 하나만 추가해도 확 달라집니다.
  • Chorus는 마지막에. 음악이 충분히 쌓인 후 올려야 클라이맥스 느낌이 납니다.
  • 조합을 천천히 바꾸세요. 한 번에 3개 이상 바꾸면 뭐가 바뀐지 모릅니다.
  • 마음에 드는 조합은 즉시 저장. 공식 사이트에서 믹스 코드로 복원할 수 있습니다.
  • 헤드폰으로 들으세요. 스피커보다 각 소리의 레이어가 훨씬 잘 들립니다.
  • 다른 사람 믹스를 들어보세요. 커뮤니티 상위 믹스에서 레이어 구성법을 배울 수 있습니다.
  • 같은 버전을 여러 번. 같은 버전도 조합을 달리하면 장르가 완전히 바뀝니다.
🗃️장르별 추천 레이어 구성
만들고 싶은 느낌레이어 전략
미니멀·차분Beat 1 + Melody 1. 나머지 비움. 여백이 핵심.
그루비·댄서블Beat 2 + Effect 1 + Voice 1. 리듬 레이어 중심.
풀 밴드 사운드Beat 1 + Effect 1 + Melody 1 + Voice 1 + Chorus 1. 5타입 균형.
보너스 노리기한 타입을 3개 이상 올리고 나머지 슬롯을 순서대로 교체.
앰비언트·몽환Effect 2 + Melody 1. Beat 없이. 둥둥 떠다니는 느낌.
🟣 Sprunki — 팬메이드 모드의 혁명
2024년 가장 화제가 된 Incredibox 팬메이드 버전. 원작보다 더 많이 알려졌다는 평가도 나올 정도입니다.
🌟Sprunki가 뭔가요?
  • 팬이 만든 Incredibox 모드입니다. 원작 게임 엔진을 기반으로, 다른 팬들이 독창적인 캐릭터·사운드·배경을 집어넣었습니다.
  • 수십 가지 파생 버전이 존재하며, 대부분 브라우저에서 무료 플레이가 가능합니다.
  • 2024년 하반기 틱톡·유튜브에서 폭발적으로 바이럴되며 Z세대를 중심으로 크게 유행했습니다.
  • 공식 게임과는 별개이지만, So Far So Good 측에서 공식적으로 협업하는 방향으로 발전 중입니다.
🧟Sprunki 호러 모드 — 왜 화제가 됐나
특정 캐릭터 조합을 발동하면 배경이 갑자기 어두워지고 피가 흐르며 무서운 음악으로 바뀌는 숨겨진 모드가 존재합니다.
  • 달달한 음악 게임인 줄 알고 하다가 갑자기 공포 분위기로 전환되는 반전이 충격적이라 SNS에서 크게 퍼졌습니다.
  • 호러 모드 발동 조건은 특정 조합 — 공개된 조합을 검색하면 찾을 수 있습니다.
  • 유튜브에 "Sprunki horror mode" 반응 영상이 수백만 뷰를 기록했습니다.
  • 이것이 알려지면서 Incredibox 원작까지 다시 주목받는 계기가 됐습니다.

  • 공식 게임이 아닙니다. So Far So Good의 공식 제품이 아니며 팬이 만든 비공식 파생작입니다.
  • 브라우저에서 무료이지만, 수상한 광고나 다운로드 유도 사이트를 조심하세요. 공식 플레이 채널은 검색으로 확인하는 것이 안전합니다.
  • 호러 모드는 연령 제한이 있습니다. 피·공포 요소가 있으므로 어린이 시청에 부적합합니다.
  • 버전이 너무 많아 품질 차이가 큽니다. 조회수·평점이 높은 것을 먼저 해보세요.

💬자주 묻는 질문
무료로 할 수 있나요?incredibox.com에서 v1 Alpha만 무료. 전 버전은 Steam이나 모바일 앱 유료 구매 필요. Sprunki 계열은 브라우저 무료.
한국어 지원되나요?게임 자체에 텍스트가 거의 없어서 언어 장벽 없음. UI는 영어지만 아이콘·드래그만으로 플레이 가능.
만든 음악을 유튜브에 올려도 되나요?원칙적으로 So Far So Good의 음원 저작권이 있습니다. 비상업적·팬 콘텐츠 용도로는 대부분 묵인하지만, 수익화 전에는 공식 정책 확인 권장.
Sprunki는 공식인가요?아닙니다. 팬메이드 비공식 모드입니다. 다만 So Far So Good 측에서 협업을 긍정적으로 검토 중.
새 버전이 나오나요?v10 Wekiddy 이후 소식은 아직 공식 발표 없음. 스팀·공식 SNS를 팔로우하면 업데이트 알림을 받을 수 있습니다.
