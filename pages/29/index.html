01 데이터팩 폴더 구조
데이터팩은 세계(World) 폴더 안 datapacks/에 넣으면 자동으로 인식됩니다. 바닐라 마인크래프트에 모드 없이 커스텀 기능을 추가하는 공식 방법.
# 기본 폴더 구조 my_datapack/ ├── pack.mcmeta # 필수 - 팩 정보 ├── pack.png # 선택 - 아이콘 이미지 └── data/ ├── minecraft/ # 바닐라 오버라이드 │ └── tags/ │ └── functions/ │ ├── load.json # 세계 로드시 실행 │ └── tick.json # 매 틱(1/20초) 실행 └── mypack/ # 내 네임스페이스 ├── functions/ │ ├── main.mcfunction │ └── utils/ │ └── helper.mcfunction ├── advancements/ ├── loot_tables/ ├── predicates/ ├── recipes/ └── tags/ ├── blocks/ ├── items/ └── functions/

01 /execute — 데이터팩의 핵심 명령어
/execute는 명령어 실행 문맥(context)을 바꾸는 명령어. 하위명령을 체인처럼 연결해 복잡한 조건과 동작을 구현.
as @a
실행자(executor)를 대상으로 변경
@s 가 선택된 플레이어 각각을 가리키게 됨.
execute as @a run say 안녕 # 모든 플레이어가 각자 "안녕" 말함
at @s
실행 위치를 대상 위치로 이동
as와 함께 쓰면 각 플레이어 위치에서 명령어 실행.
execute as @a at @s run summon minecraft:lightning_bolt ~ ~ ~ # 모든 플레이어 위치에 번개 소환
if block ~ ~-1 ~ stone
특정 좌표의 블럭 조건 확인
execute as @a at @s if block ~ ~-1 ~ minecraft:stone run say 돌 위에 서 있음 # 플레이어 발 아래 블럭이 돌인 경우만
if entity @s[tag=vip]
엔티티 존재/조건 확인
execute if entity @a[tag=vip] run say VIP 플레이어 있음
if score @s kills matches 10..
스코어보드 값 조건 확인
execute as @a if score @s kills matches 10.. run function mypack:reward # 킬 10 이상인 플레이어에게 보상
unless
if 의 반대 조건
execute unless entity @a[gamemode=creative] run say 서바이벌 플레이어만 있음
positioned 0 64 0
실행 위치를 절대 좌표로 이동
execute positioned 100 64 200 if block ~ ~ ~ minecraft:chest run say 해당 좌표에 상자 있음
store result score @s obj
명령어 결과를 스코어보드에 저장
execute store result score @s health run data get entity @s Health 1 # 플레이어 체력값을 health 오브젝트에 저장
in minecraft:the_nether
특정 차원으로 실행 위치 이동
overworld · the_nether · the_end 선택 가능.
rotated as @s
실행 회전을 대상의 바라보는 방향으로 설정
execute as @a at @s rotated as @s run summon minecraft:arrow ^ ^ ^3 # 플레이어가 바라보는 방향 앞 3블럭에 화살 소환
02 /scoreboard — 변수 시스템
Scoreboard는 데이터팩에서 변수 역할. 플레이어·엔티티별 정수값을 저장·연산.
scoreboard objectives add kills playerKillCount
오브젝트(변수군) 생성
criterion: dummy(수동) · playerKillCount · deathCount · health · xp · level · food · air
scoreboard players set @s kills 0
값 설정 (절대값)
scoreboard players set @s kills 0 scoreboard players add @s kills 1 # +1 scoreboard players remove @s kills 1 # -1 scoreboard players reset @s kills # 초기화
scoreboard players operation
스코어 간 연산
# target obj 연산자 source obj scoreboard players operation @s total += @s bonus # 연산자: += -= *= /= %= = < > <> # < 는 최솟값, > 는 최댓값, <> 는 swap
scoreboard objectives setdisplay sidebar
사이드바/탭/벨로우네임 표시
sidebar · list · belowName 위치 선택.
scoreboard objectives setdisplay sidebar kills

🎯 선택자 & 조건
@a · @p · @e · @r · @s · 선택자 인수 · Predicate JSON
01 기본 선택자
@a
모든 플레이어
All players — 온라인 플레이어 전체.
@p
가장 가까운 플레이어
Nearest Player — 실행 위치 기준 최근접 1명.
@e
모든 엔티티 (플레이어 포함)
All Entities — type 인수로 좁히는 게 일반적.
@r
랜덤 플레이어 1명
Random player. limit 인수로 n명 선택 가능.
@s
명령어 실행자 자신
execute as 로 바뀐 실행자 = @s.
02 선택자 인수 [...]
[type=zombie]
엔티티 타입 필터
@e[type=minecraft:zombie] @e[type=!minecraft:player] # 플레이어 제외
[distance=..10]
거리 필터
..10 = 10 이하 · 5.. = 5 이상 · 3..8 = 3~8블럭
@a[distance=..5] # 반경 5 내 플레이어
[limit=1,sort=nearest]
수 제한 · 정렬
sort: nearest · furthest · random · arbitrary
[tag=vip]
태그 필터
tag=!vip 로 태그 없는 엔티티 선택.
[scores={kills=5..}]
스코어 기반 필터
@a[scores={kills=10..,deaths=..3}] # 킬 10 이상이고 사망 3 이하인 플레이어
[gamemode=survival]
게임모드 필터
[name="플레이어명"]
이름 필터
name=!"이름" 으로 특정 이름 제외.
[nbt={OnGround:1b}]
NBT 조건 필터
@e[type=zombie,nbt={IsBaby:1b}] # 아기 좀비만 선택
[predicate=mypack:cond]
Predicate JSON 조건 적용
복잡한 조건을 JSON 파일로 분리. 아래 참고.
[x=0,y=64,z=0,dx=10,dy=5,dz=10]
특정 박스 영역 내 필터
x/y/z 시작점, dx/dy/dz 크기(+방향으로만).
03 Predicate — 복합 조건 JSON
Predicate는 data/mypack/predicates/ 폴더에 JSON으로 작성. 복잡한 조건을 재사용 가능한 파일로 분리.
data/mypack/predicates/is_raining.json
{ "condition": "minecraft:weather_check", "raining": true } # 사용: execute if predicate mypack:is_raining
data/mypack/predicates/full_hp.json
{ "condition": "minecraft:entity_properties", "entity": "this", "predicate": { "type": "minecraft:player", "nbt": "{Health:20.0f}" } }
자주 쓰는 condition 종류
entity_properties
엔티티 속성 검사 (type, nbt, location 등)
entity_scores
스코어보드 값 범위 확인
location_check
위치·바이옴·구조물·빛 레벨 확인
random_chance
확률 기반 조건 (0.0~1.0)
all_of / any_of / inverted
AND / OR / NOT 논리 결합

03 커스텀 레시피 (Crafting Recipe)
모양 있는 제작법 (shaped)
// data/mypack/recipes/super_sword.json { "type": "minecraft:crafting_shaped", "pattern": [ "DDD", " S ", " S " ], "key": { "D": {"item": "minecraft:diamond"}, "S": {"item": "minecraft:stick"} }, "result": { "item": "minecraft:diamond_sword", "count": 1 } }
모양 없는 제작법 (shapeless)
// data/mypack/recipes/coal_to_diamond.json { "type": "minecraft:crafting_shapeless", "ingredients": [ {"item": "minecraft:coal_block"}, {"item": "minecraft:coal_block"}, {"item": "minecraft:coal_block"} ], "result": { "item": "minecraft:diamond", "count": 1 } }
제련 레시피 (smelting)
{ "type": "minecraft:smelting", "ingredient": {"item": "minecraft:stone"}, "result": "minecraft:smooth_stone", "experience": 0.1, "cookingtime": 200 } # type: smelting · blasting · smoking · campfire_cooking
레시피 삭제: data/minecraft/recipes/ 에 같은 이름의 빈 파일 또는 {"type":"minecraft:crafting_special_*"} 으로 오버라이드

# data/mypack/functions/setup.mcfunction (load 시 실행) scoreboard objectives add kills playerKillCount scoreboard objectives add deaths deathCount scoreboard objectives setdisplay sidebar kills tellraw @a {"text":"[킬 카운터] 시스템 로드됨","color":"green"} # data/mypack/functions/tick.mcfunction (매 틱 실행) execute as @a if score @s kills matches 10 run function mypack:reward_10kills execute as @a if score @s kills matches 50 run function mypack:reward_50kills # data/mypack/functions/reward_10kills.mcfunction title @s title {"text":"10킬 달성!","color":"gold","bold":true} playsound minecraft:entity.player.levelup master @s ~ ~ ~ 1 1 give @s minecraft:diamond 5 particle minecraft:totem_of_undying ~ ~1 ~ 0.5 1 0.5 0.1 50 force @s scoreboard players set @s kills 11 # 중복 방지 (10→11로 올려서 다시 안걸림)

03 게임 타이머
# setup.mcfunction 에서 scoreboard objectives add timer dummy scoreboard players set global timer 2400 # 2400틱 = 2분 # tick.mcfunction scoreboard players remove global timer 1 # 타이머 표시 (actionbar) execute store result storage mypack:temp time int 0.05 run scoreboard players get global timer tellraw @a {"score":{"name":"global","objective":"timer"},"text":"틱 남음"} # 타이머 종료 감지 execute if score global timer matches ..0 run function mypack:game_over # game_over.mcfunction title @a title {"text":"⏰ 시간 종료!","color":"red","bold":true} playsound minecraft:block.note_block.bell master @a ~ ~ ~ 1 0.5 scoreboard players set global timer -1 # -1로 중복 실행 방지

# 랜덤 이벤트: /random 명령어는 1.20+에서 지원 scoreboard objectives add rng dummy # random.mcfunction — 0~99 랜덤 값 생성 execute store result score @s rng run random value 0..99 # 1.20+ 전용 # 구버전 방식: loot table random execute store result score @s rng run loot spawn ~ ~-10 ~ loot mypack:random_number # 조건 분기 execute as @a if score @s rng matches 0..24 run function mypack:event/lightning # 25% 확률 번개 execute as @a if score @s rng matches 25..49 run function mypack:event/heal # 25% 확률 회복 execute as @a if score @s rng matches 50..74 run function mypack:event/zombie_swarm # 25% 확률 좀비 떼 # 75..99: 아무 일도 없음 (25%)
05 Storage — 전역 데이터 저장
Storage (1.15+)는 플레이어/엔티티와 무관하게 임의 NBT 데이터를 저장하는 전역 공간.
# storage에 값 저장 data modify storage mypack:global GamePhase set value "active" data modify storage mypack:global BossHP set value 500 # storage에서 값 읽기 data get storage mypack:global GamePhase data get storage mypack:global BossHP # storage → scoreboard 로 복사 execute store result score global boss_hp run data get storage mypack:global BossHP # 조건 분기에 활용 execute if data storage mypack:global {GamePhase:"active"} run function mypack:game_loop
06 가짜 플레이어 — 상수·전역 변수
가짜 플레이어(fake player)는 스코어보드에서 실제 플레이어가 아닌 이름을 사용해 상수/전역 변수 역할.
# setup.mcfunction 에서 상수 설정 scoreboard objectives add const dummy scoreboard players set #2 const 2 scoreboard players set #100 const 100 scoreboard players set #1000 const 1000 # 활용: 점수를 100으로 나누기 (백분율) scoreboard players operation @s percent = @s score scoreboard players operation @s percent *= #100 const scoreboard players operation @s percent /= global max_score # 전역 카운터 (# 접두사 = 가짜플레이어 관례) scoreboard players add #total kills_total 1 scoreboard players get #total kills_total
07 디버그 · 자주 쓰는 패턴
# 특정 조건에서만 디버그 메시지 출력 execute if score #debug const matches 1 run tellraw @a ["[DEBUG] 현재 phase: ", {"score":{"name":"global","objective":"phase"}}] # 엔티티가 존재하는지 확인 execute unless entity @e[tag=boss,limit=1] run function mypack:spawn_boss # 재귀로 루프 구현 (주의: 최대 65536번) # loop.mcfunction scoreboard players remove #i temp 1 function mypack:do_work execute if score #i temp matches 1.. run function mypack:loop # 재귀 # 사용: #i 에 횟수 설정 후 호출 scoreboard players set #i temp 10 function mypack:loop
