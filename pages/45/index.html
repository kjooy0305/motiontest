BDEngine 완전 정복 Minecraft Display Entity Editor

BDEngine은 마인크래프트 Display Entity(1.19.4+)를 웹 브라우저에서 3D로 모델링·애니메이션하는 온라인 에디터입니다. 모드·리소스팩 없이 Block Display · Item Display · Text Display를 제작하고 /summon 명령어 또는 데이터팩으로 내보낼 수 있습니다.
화면 구성 개요
🖥 Main Dock (메인 독)
화면 중앙 상단에 위치한 주요 도구 모음. 오브젝트 추가·변환·그룹화 등 핵심 기능 버튼이 모여 있음.
🔘 Dock Buttons (독 버튼)
독 옆·아래에 배치된 보조 버튼. Asset Library 열기, 모드 전환, 설정, 내보내기 등 빠른 접근 제공.
📋 Context Menu (우클릭 메뉴)
오브젝트나 씬을 우클릭하면 나타나는 상황별 메뉴. 복사·붙여넣기·삭제·그룹화 등 상황에 맞는 옵션 제공.
⬇ Bottom Panel (하단 패널)
씬 하단에 위치. 애니메이터 타임라인 접근, 오브젝트 속성(위치·회전·스케일 수치) 직접 입력.
📚 Asset Library (에셋 라이브러리)
모든 블록·아이템·텍스트를 아이콘 형태로 표시. 검색창으로 원하는 블록을 빠르게 찾아 씬에 배치. 커스텀 헤드도 포함.
▶ Side Panel (사이드 패널)
우측 패널. 선택한 오브젝트의 속성(Transform, NBT, 이름 등) 표시 및 편집. 모든 사이드 패널은 접기(collapse) 가능.
⏱ Timeline (타임라인)
애니메이터 모드에서 표시. 키프레임 생성·편집, 재생·정지, 루프 제어, 그룹 헤더로 구간 분리, 중첩 그룹 접기 지원.
🌐 Viewport (뷰포트)
3D 작업 공간. 중앙에 위치하며 마우스로 카메라 조작. 오브젝트 클릭·드래그로 선택 및 변환 기즈모 조작.

오브젝트 추가
🧱 Block Display 추가
Asset Library에서 원하는 블록 아이콘 클릭 → 씬에 블록 배치. 검색창에 이름 입력으로 빠른 검색.
🗡 Item Display 추가
Asset Library의 아이템 탭에서 선택. 검, 도구, 갑옷 등 모든 아이템 지원.
🔤 Text Display 추가
Text 탭에서 텍스트 추가. 폰트 색상·배경·투명도·정렬·라인 너비 설정 가능.

다른 곳에서 복사한 /summon 명령어를 에디터에서 Ctrl+V로 붙여넣기 → 자동으로 모델 로드.

신기능
카메라 애니메이션 & 컷신
🎥 카메라 애니메이션
플레이어의 카메라를 애니메이션화하여 모드·리소스팩 없이 컷신(Cutscene)을 제작. 단 하나의 명령어로 실행.
📱 Tracking Camera (폰 카메라)
WebXR 지원 스마트폰을 가상 카메라로 변환. 폰을 들고 움직이면 카메라 움직임이 실시간으로 녹화됨. 독바 Extra 메뉴에서 접근.
독바 Extra 메뉴 → Tracking Camera 활성화
스마트폰에서 QR 코드 스캔
폰을 움직여 카메라 경로 녹화 시작
녹화 중지 후 타임라인에서 구간 재편집 가능
신기능 카메라

타임라인에 영상 파일을 레퍼런스로 삽입. 영상과 타임라인이 동기화되어 모션 캡처 참고 작업에 유용.

물리 시뮬레이션
⚙ Physics Simulation
물리 시뮬레이션을 실행하고 결과를 애니메이션으로 베이크(Bake). 자연스러운 낙하·충돌·튕김 표현 가능.
설정 가능 항목:
Collision
충돌 감지 여부
Friction
마찰력
Bounce
탄성(튕김)
Kinematic Damping
운동 감쇠
신기능 애니메이션
내보내기 (Export)
🔧 Basic (기본 명령어)
모델을 /summon 명령어로 내보내기. 커맨드 블록에 붙여넣기 가능. 가장 기본적인 내보내기 방식.
내보내기
🎬 Animations (애니메이션)
애니메이션을 포함한 명령어 또는 데이터팩으로 내보내기. 단 하나의 명령으로 애니메이션 실행.
내보내기 애니메이션
🔊 Sounds (사운드)
사운드 이벤트를 포함한 내보내기. 타임라인에서 설정한 사운드 트리거가 포함된 데이터팩 생성.
내보내기
⚙ Functions (함수)
Functions 모드에서 작성한 커스텀 mcfunction 파일을 포함한 데이터팩 내보내기.
내보내기
📦 Datapack (데이터팩)
전체 프로젝트를 마인크래프트 데이터팩 형식으로 내보내기. 서버에 직접 업로드 가능.
내보내기
🔌 Axiom Mod 지원
카탈로그에 모델 게시 시 Axiom 모드용 명령어도 자동 생성. 복잡한 모델을 Axiom으로 단 하나의 명령어로 삽입.
🖥 Minecraft Server Export
서버용 내보내기 옵션. 플러그인이 모델 또는 전체 프로젝트에 서버에서 직접 접근 가능하도록 설정.
신기능
클라우드 저장 & 버전 관리
☁ 클라우드 자동 저장
인터넷 연결 상태라면 어느 기기에서든 프로젝트 접근 가능. 서버 불안정 시에도 로컬 캐시로 동기화 유지.
🕐 100회 저장 히스토리
최근 100번의 저장 내역 보관. 원하는 시점으로 클릭 한 번에 롤백 가능. 실수로 삭제한 작업도 복원 가능.
💾 Auto Save (자동 저장)
작업 중 일정 간격으로 자동 저장. 예기치 않은 브라우저 종료 등에서 데이터 손실 방지.
신기능
특수 모드
🕶 Immersion Mode (몰입형 모드)
마인크래프트 1인칭 스타일로 씬 내부에 들어가 모델링. 실제 게임 화면처럼 빌드. 독 버튼에서 활성화.
신기능
🤝 Share Party (공유 파티)
공개 서버 참여 또는 비공개 룸 생성. BDEngine 내에서 채팅·모델 공유·함께 제작 가능. 실시간 협업 기능.
신기능
📦 Hitbox Mode (히트박스 모드)
모델의 충돌 히트박스를 전용 레이어에서 제작. 게임·맵에서 실제 충돌 영역 커스터마이징.
신기능
⚙ Functions Mode (함수 모드)
BDEngine 내에서 .mcfunction 파일을 직접 작성. 문법 힌팅(Syntax Hinting) 내장으로 편리한 코딩.
신기능
🎵 Sound Edit Mode (사운드 편집)
애니메이션 타임라인에 사운드 이벤트 삽입. 특정 프레임에 소리 재생 트리거 설정 가능.
신기능
✈ Free Fly Camera Mode
WASD 키로 씬을 자유롭게 날아다니며 탐색. 마인크래프트 스펙테이터 모드와 유사한 조작감.
성능 & 설정
⚡ Mesh Instancing 최적화
렌더링 엔진 최적화로 대형 모델 작업 시 성능 최대 90% 향상. 선택·복사·클론·그룹화 등 연산이 수십 초 → 1초 미만으로 단축.
📉 LiteUI Mode
UI 블러 및 투명도 효과를 비활성화하여 저사양 기기에서도 부드러운 작업 환경. Settings → LiteUI Mode 에서 토글.
🌐 다국어 지원
한국어·영어·러시아어·중국어 등 다국어 인터페이스 지원. Settings에서 언어 변경 가능.
🔤 커스텀 헤드 (HeadCreator)
닉네임으로 플레이어 머리 추가. 또는 픽셀 아트 도구로 BDEngine 내에서 직접 그려 커스텀 텍스처 제작. 리소스팩 불필요.
Display Entity 기본 개념
🧱 Block Display
블록을 엔티티로 표현. 자유로운 위치·회전·스케일 설정. 1.19.4+ 필요. 모드 없이 모든 플레이어에게 보임.
🗡 Item Display
아이템(검, 도구, 갑옷 등)을 엔티티로 표현. 아이템 고유 모양과 텍스처 유지.
🔤 Text Display
텍스트를 3D 공간에 배치하는 엔티티. 색상·배경·투명도·정렬·그림자 설정 가능.
🔧 Transform 속성
모든 Display 엔티티는 Translation(위치), Left/Right Rotation(회전), Scale(스케일) 변환을 지원. Interpolation(보간) 틱으로 부드러운 전환 가능.
📋 /summon 명령어 형식
BDEngine이 생성하는 기본 명령어 형식:
/summon block_display ~ ~ ~ {block_state:{Name:"minecraft:stone"},transformation:{...},brightness:{...}}
🔌 Axiom Mod 연동
카탈로그에 게시한 모델은 Axiom 모드용 명령어도 생성. 복잡한 구조물을 마인크래프트 내에서 단번에 삽입.
