데이터팩 · 리소스팩 생성기

이름만 정하면 바로 다운로드
⚙️ 생성기
이름과 형태만 정하면 바로 작동하는 zip이 만들어집니다. 압축을 풀 필요 없이 폴더에 넣고 /reload만 하면 끝입니다.
📝 기본 설정
게임 목록에 보이는 이름입니다. 한글도 됩니다.
함수 이름이 mypack:load 처럼 됩니다. 소문자·숫자·_·-만 가능.
왼쪽=데이터팩, 오른쪽=리소스팩. 모르면 그대로 두세요 — supported_formats가 넓게 잡혀 있어 대부분 그냥 작동합니다.
🧩 넣을 내용
zip은 브라우저 안에서 직접 만들어집니다. 서버로 아무것도 전송되지 않습니다.
📂 만들어질 파일
📥
🗂️ 구조 설명 — 각 파일이 왜 필요한가
생성기가 만드는 파일들의 역할입니다. 이걸 알면 직접 고칠 수 있습니다.

📦 데이터팩

<월드 폴더>/datapacks/내팩.zip
├── pack.mcmeta          ← 반드시 zip 최상단! 없으면 인식 안 됨
└── data/
    ├── minecraft/
    │   └── tags/function/
    │       ├── load.json    ← 로드될 때 실행할 함수 목록
    │       └── tick.json    ← 매 틱 실행할 함수 목록
    └── <네임스페이스>/
        ├── function/        *.mcfunction  →  /function ns:이름
        ├── recipe/          제작법
        ├── loot_table/      전리품 표
        ├── advancement/     발전 과제 = 이벤트 감지 + 보상
        ├── predicate/       재사용 가능한 조건
        ├── item_modifier/   아이템 변형 규칙
        ├── tags/            블록·아이템·엔티티 묶음
        ├── dimension/       커스텀 차원
        └── worldgen/biome/  커스텀 바이옴
📄pack.mcmeta
팩의 신분증입니다. 이게 최상단에 없으면 게임이 팩으로 인식하지 않습니다.
pack_format은 버전 번호이고, supported_formats 범위 안에 들면 숫자가 정확하지 않아도 경고 없이 로드됩니다. 생성기가 자동으로 넣어 줍니다.
🔁load.json / tick.json
load = 데이터팩이 로드·리로드될 때 1회 실행. 스코어보드 등록 같은 선언만 넣습니다.
tick = 매 틱(1초 20번) 실행. 여기가 무거우면 렉이 생깁니다.
둘 다 minecraft 네임스페이스의 태그에 내 함수를 등록하는 방식입니다.
🧹uninstall.mcfunction
스코어보드·팀·보스바는 데이터팩을 지워도 월드에 남습니다. 그래서 좋은 팩은 반드시 제거 함수를 제공합니다. 이게 없으면 미완성입니다.
🎁커스텀 아이템 세트
give(지급) → detect(우클릭 감지) → use(효과)의 3단 구조로 생성됩니다.
마인크래프트에는 우클릭 이벤트가 없어서 통계 점수 + 리셋 방식으로 우회합니다. 이게 커스텀 아이템의 표준 패턴입니다.

🎨 리소스팩

<.minecraft>/resourcepacks/내팩.zip
├── pack.mcmeta
├── pack.png             ← 목록에 보이는 아이콘 (선택)
└── assets/
    ├── minecraft/       ← 바닐라를 덮어쓸 때
    │   └── lang/ko_kr.json
    └── <네임스페이스>/
        ├── items/       아이템 모델 정의  (1.21.4+)
        ├── models/item/ 모델
        ├── textures/item/ 텍스처 PNG
        ├── lang/        번역
        └── sounds.json  소리 정의
⚠
1.21.4에서 아이템 외형 방식이 바뀌었습니다.
1.21.4 이상 — assets/ns/items/*.json(아이템 모델 정의) + item_model 컴포넌트. 바닐라 모델을 덮어쓰지 않아 다른 리소스팩과 충돌하지 않습니다.
1.21.3 이하 — 바닐라 모델을 덮어쓰고 custom_model_data 숫자로 분기.
생성기가 선택한 버전에 맞춰 알아서 만들어 줍니다.

📛 이름 규칙 — 어기면 조용히 작동하지 않습니다

항목규칙
네임스페이스 · 파일명 · 폴더명영문 소문자, 숫자, _, -, .만. 대문자·한글·공백 금지
함수 이름네임스페이스:function 폴더 이후 경로 (확장자 제외)
예) data/mypack/function/a/b.mcfunction → mypack:a/b
확장자함수는 .mcfunction, 나머지는 .json
zip 구조pack.mcmeta가 zip 최상단에. 폴더가 한 겹 더 있으면 인식 안 됨
팩 이름(표시명)한글·공백 자유. 이건 pack.mcmeta 안의 텍스트일 뿐
🚫
가장 흔한 3가지 실패:
① zip 안에 폴더가 한 겹 더 들어감 → 생성기로 받으면 이 문제가 없습니다
② 폴더 이름을 functions(복수형)로 씀 → 1.21부터는 function(단수) — 생성기가 버전에 맞춰 처리
③ 네임스페이스에 대문자·한글 사용 → 생성기가 입력을 자동 교정
🔢 버전 · pack_format 표
숫자가 안 맞으면 목록에서 빨강/노랑으로 표시되지만, supported_formats가 있으면 대부분 그냥 작동합니다.

🔍 내 버전의 정확한 숫자 찾는 법

1️⃣jar에서 확인 (가장 정확)
.minecraft/versions/<버전>/<버전>.jar를 압축 프로그램으로 열고 version.json을 봅니다. 
{
  "id": "1.21.5",
  "pack_version": {
    "resource": 55,
    "data": 71
  }
}
data=데이터팩, resource=리소스팩입니다.
2️⃣그냥 두기
생성기는 supported_formats를 4 ~ 9999로 넓게 잡습니다. 이 범위에 들면 경고 없이 정상 로드됩니다. 숫자를 몰라도 대부분 문제가 없습니다.
3️⃣증상으로 판단
데이터팩 목록에 빨간색/노란색으로 뜨거나 "다른 버전용" 경고가 나오면 숫자 문제입니다. 아예 목록에 안 뜨면 숫자가 아니라 폴더 구조나 zip 문제입니다.
📌
1.21에서 폴더 이름이 단수형으로 바뀌었습니다. functions→function, advancements→advancement, loot_tables→loot_table, predicates→predicate, recipes→recipe, structures→structure, tags/functions→tags/function 등. 생성기가 선택한 버전에 맞는 이름으로 만듭니다.
🚀 받은 다음에 할 것
zip을 넣고 /reload까지 됐다면, 이제 내 것으로 고칠 차례입니다.

✅ 설치 확인

/reload                    ← 데이터팩 적용. 빨간 오류가 나오면 그게 답이다
/datapack list             ← 활성 목록에 내 팩이 있는지
/function                  ← 여기까지 치면 자동완성에 내 함수가 뜬다
F3+T                       ← 리소스팩 새로 불러오기 (게임 재시작 불필요)
🔍
진단 순서: ① /reload 오류 메시지 읽기 → ② /datapack list로 로드 확인 → ③ /function 자동완성에 뜨는지 → ④ 안 뜨면 폴더 이름(단수/복수)이나 zip 구조 문제.

✂️ 어디를 고치면 되나

하고 싶은 것고칠 파일
시작 메시지 바꾸기function/load.mcfunction의 tellraw
매 틱 동작 추가function/tick.mcfunction — 가볍게 유지할 것
아이템 이름·능력 바꾸기function/item/give.mcfunction
우클릭 효과 바꾸기function/item/use.mcfunction
아이템 종류 추가item/detect.mcfunction에 분기 한 줄 추가
아이템 모양 바꾸기리소스팩 textures/item/*.png를 16×16로 교체
제작법 바꾸기recipe/*.json의 pattern과 key
드롭 아이템 바꾸기loot_table/*.json
제거하기/function ns:uninstall 실행 후 파일 삭제
