핵심 블록

Callout으로 핵심 개념 강조, Synced Block으로 공통 공식을 여러 과목에 연결.

✅과제·시험 트래커 DB
속성 구성

과목(Select), 과제명(Title), 마감일(Date), 비중(Number·%), 상태(Status), 제출 링크(URL)

뷰 활용

Table 뷰 → 마감일 오름차순 정렬 | Calendar 뷰 → 월별 마감일 한눈에 | Board 뷰 → 상태별(할 일/진행중/완료) 이동

📖독서·논문 기록
속성 구성

제목(Title), 저자(Text), 분야(Multi-select), 읽은 날(Date), 별점(Number), 핵심 내용(Text), 인용 페이지 링크

갤러리 뷰

표지 이미지를 Card preview로 설정 → 읽은 책이 책장처럼 보임

🎯학기 대시보드
구조

한 페이지에 이번 주 할 일(Linked DB·필터:이번 주), 오늘 일정(캘린더 임베드), 과목별 성적 현황(Rollup), 메모 영역을 컬럼으로 배치.

핵심

모든 정보는 다른 DB에서 Linked view로 가져오기 → 한 곳에서 수정하면 대시보드도 자동 반영.

🗂️포트폴리오·이력서
공개 공유

프로젝트 갤러리 DB를 웹에 게시하면 URL 하나로 포트폴리오 공유. Plus 플랜은 커스텀 도메인 사용 가능.

속성 구성

프로젝트명, 기간(Date Range), 사용 기술(Multi-select), GitHub(URL), 데모 영상(Files), 역할(Select)

🔁습관·루틴 트래커
Daily Log DB

날짜(Title·자동 날짜 버튼), 운동(Checkbox), 공부(Number·시간), 기분(Select), 오늘 한 일(Text)

버튼 자동화

/button으로 "오늘 일지 만들기" 버튼 → 클릭 시 오늘 날짜 레코드 자동 생성

👥팀 프로젝트 협업
Plus 게스트 무제한

팀원을 게스트로 무제한 초대. 페이지별 권한 설정(편집/댓글/읽기 전용).

구조 추천

팀 공간 페이지 → 회의록 DB / 역할 분담 DB / 리소스 페이지. @멘션으로 담당자 지정, 댓글로 피드백.
