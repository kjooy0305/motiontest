01 Vector — R의 기본 단위
R의 모든 값은 벡터다. 숫자 하나도 길이 1짜리 벡터. 벡터 연산은 자동으로 원소별(element-wise) 적용됨.

01 기술통계 (Descriptive Statistics)
mean(x) · median(x)
평균 · 중앙값
공식평균(mean) = Σxᵢ / n 중앙값(median) = 정렬 후 가운데 값

x <- c(2, 4, 4, 4, 5, 5, 7, 9) var(x) → [1] 4.571429 sd(x) → [1] 2.138090
📉 산포도 측정

분위수
0.25=1사분위(Q1) · 0.5=중앙값 · 0.75=3사분위(Q3). IQR = Q3 - Q1.
x <- c(1:10) quantile(x) 0% 25% 50% 75% 100% 1.0 3.25 5.5 7.75 10.0 IQR(x) → [1] 4.5
summary(x)

상관계수 · 공분산
피어슨 상관계수 공식r = Σ[(xᵢ-x̄)(yᵢ-ȳ)] / [(n-1)·sₓ·s_y] -1 ≤ r ≤ 1 (0: 무관, ±1: 완전 선형관계)
x <- c(1,2,3,4,5) y <- c(2,4,5,4,5) cor(x, y) → [1] 0.9449112 cov(x, y) → [1] 2.1

02 확률 분포 함수
R 분포 함수 접두어 규칙: d-밀도함수(PDF) · p-누적분포(CDF) · q-분위수(역CDF) · r-난수 생성
예: dnorm · pnorm · qnorm · rnorm
rnorm(n, mean, sd)
정규분포 난수 생성
정규분포 PDFf(x) = 1/(σ√2π) · exp(-(x-μ)²/2σ²)
set.seed(42) rnorm(5, mean=0, sd=1) [1] 1.371 -0.565 0.363 0.633 0.404 pnorm(1.96) → [1] 0.9750021 # P(Z≤1.96) qnorm(0.975) → [1] 1.959964 # 95% 신뢰구간 임계값
🎲 Monte Carlo 시뮬레이션📐 통계 검정
rt(n, df)
pt(t, df)
t분포 난수 · 누적확률
t 통계량t = (x̄ - μ₀) / (s/√n) df = n-1
pt(2.0, df=9) → [1] 0.9633306 qt(0.975, df=9) → [1] 2.262157 # t 임계값
📊 소표본 평균 검정
rbinom(n, size, prob)
이항분포 난수 생성
이항분포 PMFP(X=k) = C(n,k) · pᵏ · (1-p)^(n-k) E(X) = np, Var(X) = np(1-p)
set.seed(1) rbinom(5, size=10, prob=0.5) [1] 4 4 6 6 3 dbinom(5, 10, 0.5) → [1] 0.2460938 # P(X=5)
🎯 성공/실패 실험
rpois(n, lambda)
포아송분포 난수 생성
포아송 PMFP(X=k) = e^(-λ) · λᵏ / k! E(X) = Var(X) = λ
dpois(3, lambda=2) → [1] 0.180447 # P(X=3) ppois(3, lambda=2) → [1] 0.857123 # P(X≤3)

03 가설 검정
t.test(x, mu=0)
일표본 t 검정
귀무가설 H₀: μ = μ₀t = (x̄ - μ₀) / (s/√n) p-value < 0.05 → H₀ 기각
set.seed(1); x <- rnorm(30, mean=5, sd=2) t.test(x, mu=4) t = 3.12, df = 29, p-value = 0.004 95% CI: [4.32, 5.89] → H₀ 기각 (μ≠4)
🧪 모집단 평균 검정
t.test(x, y)
이표본 t 검정 (두 집단 평균 비교)
귀무가설 H₀: μ₁ = μ₂t = (x̄₁ - x̄₂) / √(s₁²/n₁ + s₂²/n₂)
A <- c(82,88,75,90,86); B <- c(70,74,78,72,68) t.test(A, B) t = 4.12, p-value = 0.003 → 유의미한 차이
🔬 AB 테스트📊 집단 비교
chisq.test(table(x))
카이제곱 검정 (범주형 독립성 검정)
χ² 통계량χ² = Σ (관측값 - 기대값)² / 기대값 df = (r-1)(c-1)
observed <- c(30, 45, 25) chisq.test(observed, p=c(1/3, 1/3, 1/3)) X-squared = 6.5, df = 2, p-value = 0.0388
📋 빈도 분석🔗 독립성 검정
wilcox.test(x, y)
윌콕슨 검정 (비모수 t 대안)
정규성 가정 위반 시 사용. Mann-Whitney U 검정.
📊 비정규 분포 비교
shapiro.test(x)
정규성 검정 (Shapiro-Wilk)
p-value > 0.05 → 정규분포 가정 기각 실패(정규분포로 봄). n < 5000 권장.
shapiro.test(rnorm(50)) W = 0.978, p-value = 0.4843 → 정규분포로 볼 수 있음

04 회귀 분석
lm(y ~ x, data=df)
단순/다중 선형 회귀
단순 선형 회귀 모델ŷ = β₀ + β₁x + ε β₁ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)² β₀ = ȳ - β₁x̄
df <- data.frame(x=c(1,2,3,4,5), y=c(2,4,5,4,5)) model <- lm(y ~ x, data=df) summary(model)
Coefficients: (Intercept) x 2.2000 0.6000 R-squared: 0.6389 # 설명력 64% p-value: 0.1179 # 회귀선 유의성
📈 예측 모델🔗 인과 분석
predict(model, newdata)
새 데이터 예측값 계산
predict(model, newdata=data.frame(x=6)) [1] 5.8 # x=6일 때 예측값
glm(y ~ x, family="binomial")

02 선형 회귀 분석 전체 과정
# 데이터 준비 set.seed(42) n <- 100 study_hours <- runif(n, 1, 10) score <- 50 + 5 * study_hours + rnorm(n, 0, 5) df <- data.frame(study_hours, score) # 모델 적합 model <- lm(score ~ study_hours, data=df) summary(model) # Intercept ≈ 50, slope ≈ 5, R² ≈ 0.92 # 잔차 정규성 검정 shapiro.test(residuals(model)) # 시각화 plot(df$study_hours, df$score, pch=19, col="#79c0ff", main="공부시간 vs 점수") abline(model, col="red", lwd=2) # 예측 predict(model, data.frame(study_hours=c(5, 8))) # study_hours=5 → 약 75점, 8 → 약 90점
03 분류 — 로지스틱 회귀 + 정확도 평가
# 이진 분류 예제 (합격/불합격 예측) set.seed(1) df <- data.frame( score = c(rnorm(50, 75, 10), rnorm(50, 55, 10)), pass = c(rep(1, 50), rep(0, 50)) ) # 훈련/테스트 분리 idx <- sample(nrow(df), 0.8*nrow(df)) train <- df[idx, ]; test <- df[-idx, ] # 로지스틱 회귀 model <- glm(pass ~ score, data=train, family="binomial") # 예측 확률 → 클래스 변환 prob <- predict(model, test, type="response") pred <- ifelse(prob > 0.5, 1, 0) # 혼동 행렬 & 정확도 table(pred, test$pass) mean(pred == test$pass) # 정확도 ≈ 0.90
