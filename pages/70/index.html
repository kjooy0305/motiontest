🎯 한눈에 보는 구조
2급 = 필기 2과목(컴퓨터 일반 + 스프레드시트 일반) → 실기 1과목(엑셀).
1급 = 필기 3과목(컴퓨터 일반 + 스프레드시트 일반 + 데이터베이스 일반) → 실기 2과목(엑셀 + 액세스).
1급은 2급 내용을 전부 포함하고 그 위에 심화 내용이 얹히는 구조라, 1급 준비 = 2급 내용 + α 입니다.

🪟 A. 한글 Windows 운영체제

🎯운영체제의 목적 4가지
  • 처리 능력(Throughput) 향상 — 일정 시간에 처리하는 작업량 ↑
  • 응답 시간(Turnaround Time) 단축 — 요청부터 결과까지 시간 ↓
  • 신뢰도(Reliability) 향상 — 오류 없이 정확하게 처리
  • 사용 가능도(Availability) 향상 — 필요할 때 즉시 사용 가능
👉 향상 3개 + 단축 1개. "응답 시간 향상"이라 쓰면 틀린 지문입니다.
⚙️Windows의 주요 특징
  • 선점형 멀티태스킹 — OS가 CPU를 강제 회수. 특정 앱이 멈춰도 전체는 유지
  • GUI — 그래픽 아이콘·마우스 기반 사용자 인터페이스
  • PnP(Plug and Play) — 하드웨어 자동 인식·설치. 하드웨어와 OS 모두 지원해야 동작
  • OLE — 개체 연결 및 삽입. 원본을 고치면 삽입된 개체도 갱신(연결의 경우)
  • 64비트 지원 / 라이브러리 / 에어로 / 사용자 계정 컨트롤(UAC)
  • NTFS 파일 시스템 — 보안·압축·암호화·대용량 지원
🗂️파일·폴더 이름 규칙
  • 최대 255자(경로 포함), 공백 사용 가능
  • 사용 불가 문자 9개: \ / : * ? " < > |
  • 대소문자를 구분하지 않음(표시는 유지)
  • 같은 폴더 안에 동일 이름 파일·폴더 불가
  • CON, PRN, AUX, NUL 등 예약어는 사용 불가
🗑️휴지통 완전 정리
  • 드라이브마다 크기를 따로 지정 가능(기본 각 드라이브 용량의 일정 %)
  • 휴지통 파일은 복원만 가능 — 실행·편집·이름 변경 불가
  • 휴지통에 가지 않고 즉시 삭제: Shift+Delete / USB·네트워크 드라이브 파일 / 휴지통 크기보다 큰 파일 / "휴지통 사용 안 함" 설정 시 / DOS 창에서 삭제
  • 휴지통이 가득 차면 가장 오래된 항목부터 자동 삭제
📎바로 가기(단축) 아이콘
  • 확장자는 .LNK, 아이콘 좌하단에 화살표 표시
  • 원본 파일의 경로 정보만 담아 크기가 매우 작음
  • 바로 가기를 지워도 원본은 그대로. 반대로 원본을 지우면 바로 가기는 작동 불가
  • 하나의 원본에 여러 개 만들 수 있고, 폴더·드라이브·프린터에도 만들 수 있음
  • 만들기: Ctrl+Shift+드래그 또는 마우스 오른쪽 드래그
🖱️드래그 시 복사 vs 이동
같은 드라이브 드래그 → 이동 (복사하려면 Ctrl)
다른 드라이브 드래그 → 복사 (이동하려면 Shift)
프로그램(exe) 드래그 → 다른 드라이브면 바로 가기 생성
어느 경우든 Ctrl+Shift 드래그는 바로 가기 생성.

🧠 중앙처리장치(CPU)

🎛️제어 장치(Control Unit)
  • PC(프로그램 카운터) — 다음에 실행할 명령어의 주소를 기억
  • IR(명령 레지스터) — 현재 실행 중인 명령어를 기억
  • 명령 해독기(Decoder) — 명령어를 해독
  • 부호기(Encoder) — 해독된 명령을 제어 신호로 변환
  • MAR(번지 레지스터) — 주소를 기억 / MBR(버퍼 레지스터) — 내용을 기억
➕연산 장치(ALU)
  • 누산기(AC) — 연산의 중간 결과를 임시 저장 (가장 자주 출제)
  • 가산기(Adder) — 덧셈 수행 / 보수기 — 뺄셈을 위해 보수로 변환
  • 데이터 레지스터 — 연산에 사용할 데이터 저장
  • 상태 레지스터(PSW) — 연산 결과의 부호·자리올림·오버플로 등 상태 기억
  • 인덱스 레지스터 — 주소 변경(수정)에 사용

RAM휘발성, 읽기·쓰기 가능. DRAM(콘덴서, 재충전 필요, 느림·저렴 → 주기억장치) / SRAM(플립플롭, 재충전 불필요, 빠름·비쌈 → 캐시)
캐시 메모리CPU와 주기억장치 속도 차이 완화. SRAM 사용. 지역성(Locality) 원리 이용. 적중률(Hit Ratio)이 높을수록 성능↑
가상 메모리보조기억장치의 일부를 주기억장치처럼 사용. 실제보다 큰 용량의 프로그램 실행 가능. 페이징/세그먼테이션 기법
버퍼 메모리속도 차가 나는 두 장치 사이에서 데이터를 임시 저장
연관(연상) 메모리주소가 아닌 내용으로 접근. 캐시의 주소 변환 테이블(TLB)에 사용
플래시 메모리EEPROM의 일종, 비휘발성이면서 전기적으로 수정 가능. USB·SSD·스마트폰에 사용
⚠️ 최다 출제 함정 — 스풀 vs 버퍼링 vs 채널 vs DMA
스풀(SPOOL) — 인쇄할 내용을 디스크에 저장해두고 CPU는 다른 일을 함. 프린터 전용, 인쇄 속도 자체는 느려질 수 있음.
버퍼링(Buffering) — 메모리를 이용해 속도 차이를 완충. 한 작업의 입출력과 연산을 중첩.
채널(Channel) — CPU 대신 입출력을 전담 관리하는 장치. 완료되면 CPU에 인터럽트로 알림.
DMA — CPU를 거치지 않고 메모리와 주변장치가 직접 데이터를 주고받음. CPU 부담 감소.

🌐 D. 인터넷 자료 활용

🔢IPv4 vs IPv6
  • IPv4: 32비트, 8비트씩 4부분, 점(.)으로 구분, 10진수 표기 (예 192.168.0.1)
  • A~E 클래스로 나뉘며 A는 대형망, C는 소규모망, D는 멀티캐스트용
  • IPv6: 128비트, 16비트씩 8부분, 콜론(:)으로 구분, 16진수 표기
  • IPv6는 주소 고갈 해결 + 인증·암호화 기능 내장 + 실시간 QoS 지원
  • IPv6 주소 유형: 유니캐스트 / 멀티캐스트 / 애니캐스트 (브로드캐스트 없음)
🏷️도메인 · DNS · URL
  • 도메인: 숫자 IP를 사람이 읽기 쉽게 문자로 표현
  • DNS: 도메인 ↔ IP를 상호 변환해주는 시스템/서버
  • URL 구조: 프로토콜://호스트주소[:포트]/경로/파일명
  • 기본 포트: HTTP 80, HTTPS 443, FTP 21, TELNET 23, SMTP 25, POP3 110, DNS 53

🖼️비트맵 vs 벡터
비트맵(래스터) — 픽셀 집합. 사진처럼 정교한 색 표현에 유리하지만 확대하면 계단 현상이 생기고 용량이 큼. 형식: BMP·JPG·GIF·PNG·TIF·PCX. 프로그램: 포토샵·페인트샵.
벡터 — 점과 선의 수학적 함수로 표현. 확대·축소해도 손상 없음, 용량이 작음. 형식: WMF·AI·DXF·CDR. 프로그램: 일러스트레이터·코렐드로.
🗜️파일 형식 핵심
  • BMP — Windows 표준, 압축하지 않아 용량이 큼
  • GIF — 256색, 무손실 압축, 투명·애니메이션 지원
  • JPEG(JPG) — 손실 압축, 24비트 트루컬러, 압축률 조절 가능
  • PNG — GIF 대체, 무손실·투명 지원, 24비트 색상. 애니메이션은 불가
  • WAVE — 실제 소리 파형을 디지털로 샘플링, 용량 큼 / MIDI — 연주 정보만 저장, 용량 작음, 사람 목소리 표현 불가
  • MP3 — MPEG-1 Layer 3 오디오 압축, 약 1/10 압축
  • MPEG — 동영상 표준. MPEG-1(CD), MPEG-2(DVD·디지털TV), MPEG-4(모바일·저속), MPEG-7(내용 검색), MPEG-21(전자상거래 관리)
  • AVI(Windows 표준 동영상) · MOV(애플) · ASF/WMV(스트리밍) · DivX(MPEG-4 기반 고압축)
📶
스트리밍(Streaming) — 파일을 다운로드하면서 동시에 재생하는 기술. 실시간 방송에 사용되며 ASF·WMV·RAM 형식이 대표적입니다. 코덱(CODEC)은 아날로그↔디지털 변환 및 압축(COmpress)/복원(DECompress)을 담당합니다.

🧮 B. 수식과 셀 참조

📍참조 방식
  • 상대 참조 A1 — 복사하면 행·열이 함께 바뀜
  • 절대 참조 $A$1 — 복사해도 고정
  • 혼합 참조 $A1(열 고정) / A$1(행 고정)
  • F4를 누를 때마다 A1 → $A$1 → A$1 → $A1 순으로 순환
  • 다른 시트: Sheet2!A1, 시트명에 공백이 있으면 '매출 자료'!A1
  • 3차원 참조: =SUM(Sheet1:Sheet3!A1) — 여러 시트의 같은 셀 합계
  • 다른 통합 문서: [Book1.xlsx]Sheet1!$A$1
⚠️오류 값의 의미
  • ##### — 열 너비가 좁거나 날짜/시간이 음수
  • #DIV/0! — 0 또는 빈 셀로 나눔
  • #N/A — 값을 찾을 수 없음(찾기 함수)
  • #NAME? — 함수명·이름을 인식 못 함(오타, 따옴표 누락)
  • #NULL! — 교차하지 않는 두 영역의 교점을 지정
  • #NUM! — 숫자가 너무 크거나 잘못된 인수
  • #REF! — 참조하던 셀이 삭제됨
  • #VALUE! — 잘못된 자료형(숫자 자리에 문자)

📋 C. 데이터 관리와 분석

🔤정렬
  • 최대 64개 기준으로 정렬
  • 오름차순 순서: 숫자 → 문자 → 논리값(FALSE→TRUE) → 오류값 → 빈 셀
  • 빈 셀은 항상 맨 마지막(오름·내림차순 모두)
  • 글꼴 색·셀 색·조건부 서식 아이콘 기준 정렬 가능
  • 왼쪽에서 오른쪽으로(행 기준) 정렬은 [옵션]에서 지정
🔍자동 필터 vs 고급 필터
  • 자동 필터 — 조건에 맞는 행만 표시, 같은 열에 최대 2개 조건(AND/OR). 결과를 다른 곳에 복사 불가
  • 고급 필터 — 조건을 워크시트에 직접 작성. 다른 장소에 복사 가능, 중복 제거 가능
  • 고급 필터 조건: 같은 행=AND, 다른 행=OR
  • 수식을 조건으로 쓸 때는 필드명을 원본과 다르게(또는 비워두고) 작성
➗부분합
  • 실행 전 반드시 기준 필드로 정렬되어 있어야 함
  • 합계·개수·평균·최대·최소·곱·표준편차 등 사용 가능
  • 중첩하려면 두 번째부터 [새로운 값으로 대치]를 해제
  • 결과는 윤곽(개요) 기호로 수준별 표시/숨기기 가능
  • [모두 제거]로 원래 데이터로 복원
📊피벗 테이블
  • 대량 데이터를 요약·집계·분석. 필터/열/행/값 영역으로 구성
  • 원본이 바뀌어도 자동 갱신되지 않음 → [새로 고침] 필요
  • 값 요약 기준(합계·개수·평균)과 값 표시 형식(비율·누계) 변경 가능
  • 피벗 차트를 함께 만들 수 있으나 분산형·주식형·거품형은 불가
  • 슬라이서·시간 표시 막대로 시각적 필터링
🎯목표값 찾기
수식의 결과값을 알고 있을 때 그 결과를 만드는 입력값 하나를 역산합니다. [수식 셀]에는 반드시 수식이, [값을 바꿀 셀]에는 반드시 값(상수)이 있어야 하며, 값을 바꿀 셀은 수식 셀에 영향을 주는 셀이어야 합니다.
🎭시나리오 · 데이터 표 · 통합
  • 시나리오 — 여러 변수 값 조합에 따른 결과를 비교. 요약 보고서는 새 워크시트에 생성되며 원본이 바뀌어도 자동 갱신 안 됨
  • 데이터 표 — 하나(행/열) 또는 두 개 변수의 변화에 따른 결과를 한 번에. 결과는 배열 수식이라 일부만 삭제 불가
  • 통합 — 여러 시트의 데이터를 하나로 요약. 원본 데이터에 연결 옵션 체크 시 자동 갱신
✅
데이터 유효성 검사 — 셀에 입력할 수 있는 값을 제한합니다(정수·소수점·목록·날짜·시간·텍스트 길이·사용자 지정). 설명 메시지와 오류 메시지(중지/경고/정보)를 지정할 수 있으며, [잘못된 데이터]로 이미 입력된 위반 값에 동그라미를 칠 수 있습니다.

🧠 A. 마이크로프로세서와 명령어

⚖️CISC vs RISC
CISC — 명령어 많고 복잡, 길이 가변, 레지스터 적음, 주소 지정 방식 다양, 회로 복잡·전력 소모 큼, 프로그래밍 쉬움. (인텔 x86)
RISC — 명령어 적고 단순, 길이 고정, 레지스터 많음, 주소 지정 단순, 처리 속도 빠름, 컴파일러가 복잡. (ARM, 워크스테이션)
🔁병렬 처리 기법
  • 파이프라이닝 — 명령어를 여러 단계로 나눠 겹쳐서 실행. 처리량↑
  • 슈퍼스칼라 — 여러 개의 파이프라인으로 클럭당 여러 명령 처리
  • 슈퍼파이프라인 — 파이프라인 단계를 더 잘게 나눔
  • VLIW — 여러 명령을 하나의 긴 명령어로 묶어 동시 실행
  • 분류(플린): SISD / SIMD / MISD / MIMD
📮주소 지정 방식
  • 즉시(Immediate) — 오퍼랜드에 데이터가 직접 들어 있음. 가장 빠름
  • 직접(Direct) — 오퍼랜드가 데이터의 주소
  • 간접(Indirect) — 오퍼랜드가 주소가 저장된 주소. 메모리 접근이 2회 이상
  • 상대(Relative) — PC + 오퍼랜드
  • 인덱스 — 인덱스 레지스터 + 오퍼랜드 (배열 처리에 유리)
  • 레지스터 / 레지스터 간접 — 데이터·주소가 레지스터에 있음
📏시스템 성능 단위
속도: MIPS(초당 백만 명령), FLOPS(초당 부동소수점 연산), Hz(클럭).
시간: ms(10⁻³) > μs(10⁻⁶) > ns(10⁻⁹) > ps(10⁻¹²) > fs(10⁻¹⁵) > as(10⁻¹⁸).
용량: KB < MB < GB < TB < PB < EB < ZB < YB.

🧬 A. 배열 수식 — 1급의 핵심

📐 배열 수식의 원리
여러 셀을 한꺼번에 계산하는 수식으로, 입력을 마칠 때 Ctrl+Shift+Enter를 누르면 수식이 { }(중괄호)로 묶입니다. 이 중괄호는 직접 입력할 수 없습니다. 배열 수식의 결과 범위는 일부만 수정·삭제할 수 없고, 전체를 선택해야 합니다.

핵심 아이디어: 조건식 (A1:A10="서울")은 TRUE/FALSE 배열을 만들고, 이것을 곱하면 AND, 더하면 OR가 되며, TRUE는 1·FALSE는 0으로 계산됩니다.
시험에 그대로 나오는 배열 수식 패턴
용도수식
조건에 맞는 개수=SUM((조건1)*(조건2)) 또는 =COUNT(IF((조건1)*(조건2),1))
조건에 맞는 합계=SUM((조건)*(합계범위)) 또는 =SUM(IF(조건,합계범위))
조건에 맞는 평균=AVERAGE(IF(조건,평균범위))
조건에 맞는 최대·최소=MAX((조건)*(범위)) / =MIN(IF(조건,범위))
조건에 맞는 값의 순위=SUM((조건)*(범위>해당값))+1
조건에 맞는 값 찾기=INDEX(반환범위,MATCH(1,(조건1)*(조건2),0))
k번째 큰 값의 위치=INDEX(범위,MATCH(LARGE(값범위,k),값범위,0))
텍스트 결합=TEXTJOIN(구분자,TRUE,IF(조건,범위,""))
🧠
FREQUENCY·MDETERM·MINVERSE·MMULT·TRANSPOSE는 원래부터 배열을 다루는 함수입니다. TRANSPOSE는 행과 열을 바꾸며, 붙여넣을 범위를 미리 정확한 크기로 선택해야 합니다.

🗃️ A. 데이터베이스 개념

📚데이터베이스의 4대 특징
  • 실시간 접근성 — 사용자 질의에 즉시 응답
  • 계속적인 변화 — 삽입·삭제·갱신으로 항상 최신 상태 유지
  • 동시 공용 — 여러 사용자가 동시에 이용
  • 내용에 의한 참조 — 주소가 아닌 데이터 값으로 검색
⚖️DBMS 장단점
장점 — 데이터 중복 최소화, 일관성·무결성 유지, 공유·표준화, 보안 유지, 논리적·물리적 독립성.
단점 — 전문가 필요, 전산화 비용 증가, 백업·회복이 어려움, 시스템이 복잡함, 파일의 예비·회복 기법이 복잡.
🏛️3단계 스키마
  • 외부 스키마 — 개별 사용자·응용 프로그램 관점(서브 스키마). 여러 개 존재
  • 개념 스키마 — 조직 전체의 논리적 구조. 하나만 존재
  • 내부 스키마 — 물리적 저장 구조(인덱스·저장 방식)
  • 논리적 독립성 = 개념↔외부 / 물리적 독립성 = 내부↔개념
🗣️데이터 언어
  • DDL(정의어) — CREATE, ALTER, DROP : 구조 정의
  • DML(조작어) — SELECT, INSERT, UPDATE, DELETE : 데이터 처리
  • DCL(제어어) — GRANT, REVOKE, COMMIT, ROLLBACK : 권한·트랜잭션
  • DBA — DB 설계·운영·보안·백업을 총괄하는 관리자
