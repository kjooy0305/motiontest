현재 AI 이미지 생성의 주류 기술

이미지의 압축된 표현 공간
개념이미지를 고차원 픽셀 대신 저차원 잠재 벡터로 표현하는 공간. Stable Diffusion은 여기서 작업해 속도↑

VAE (Variational Autoencoder)
가변 오토인코더
역할잠재 공간 ↔ 실제 이미지 픽셀 변환. 최종 이미지 색상·선명도에 큰 영향
교체 효과vae-ft-mse-840000: 피부색·전반적 색감 개선
주의VAE 없이 구동하면 채도 낮고 회색빛 이미지 발생 가능
🔗
CLIP (Contrastive Language–Image Pre-training)
OpenAI의 텍스트-이미지 연결 모델
역할프롬프트 텍스트를 이미지와 연결되는 벡터로 변환 → U-Net에 조건 제공
CLIP Skip마지막 N개 레이어를 건너뜀. 2로 설정 시 더 창의적이나 덜 정확
🧱
U-Net
Stable Diffusion의 핵심 신경망
역할잠재 공간에서 노이즈 제거 과정을 수행. CLIP 조건을 받아 프롬프트에 맞게 노이즈 제거
⚡
CFG Scale (Classifier Free Guidance)
프롬프트 충실도
낮음 (1~5)프롬프트 무시, 매우 창의적·랜덤
중간 (7~12)균형. 대부분의 경우 권장
높음 (15+)프롬프트에 지나치게 충실 → 과포화·아티팩트
🌱
Seed (시드)
랜덤 초기값
역할노이즈 생성의 시작점. 동일 시드+동일 설정=동일 이미지 보장
활용마음에 드는 구도 발견 → 시드 고정 → 프롬프트만 바꿔가며 실험

ControlNet

Hires. fix / 업스케일
