📘 문법 가이드
KaTeX(=LaTeX 수식 문법)의 규칙은 생각보다 단순합니다. 이 페이지 하나만 이해하면 대부분의 수식을 직접 쓸 수 있습니다.
🎯
딱 세 가지만 기억하세요.
① 명령어는 \ 로 시작합니다 — \alpha, \frac, \sum
② 묶고 싶은 건 { } 로 감쌉니다 — x^{10} (중괄호는 화면에 안 보입니다)
③ 위는 ^, 아래는 _ 입니다 — x^2, a_i, x_1^2

1. 중괄호 { } 가 핵심입니다

코드결과설명
x^2한 글자면 중괄호 생략 가능
x^10틀림! 1만 올라가고 0은 내려옵니다
x^{10}맞음. 두 글자 이상은 반드시 { }
x_{i,j}아래첨자도 같은 규칙
x_1^2위아래 동시에도 가능
💡
헷갈리면 무조건 중괄호를 쓰세요. x^{2} 처럼 한 글자에 써도 결과는 똑같습니다. "귀찮아서 생략"하다 틀리는 것보다 낫습니다.

2. 분수와 근호

코드결과설명
\frac{a}{b}앞이 분자, 뒤가 분모
\frac{x+1}{x-1}여러 글자는 통째로 { } 안에
\dfrac{a}{b}본문 안에서도 크게 (display)
\sqrt{x}제곱근
\sqrt[3]{x}세제곱근 — 대괄호에 차수

3. 큰 기호 (시그마·적분·극한)

코드결과설명
\sum_{k=1}^{n} k_ 아래, ^ 위
\int_{0}^{1} x\,dx\, 는 얇은 공백
\lim_{x \to 0}극한
\prod_{i=1}^{n}총곱

4. 함수 이름 앞에는 \ 를 붙이세요

코드결과설명
sin x틀림 — s·i·n 세 변수의 곱으로 읽힙니다 (기울어짐)
\sin x맞음 — 함수로 인식되어 똑바로 섭니다
\log_2 x밑은 _ 로

5. 괄호는 \left \right 로 늘리세요

코드결과설명
(\frac{a}{b})괄호가 작아서 어색합니다
\left(\frac{a}{b}\right)내용 높이에 맞춰 자동으로 커집니다
\left| x \right|절댓값
⚠️
\left 를 썼으면 반드시 \right 로 닫아야 합니다. 짝이 안 맞으면 수식 전체가 오류로 사라집니다. 한쪽만 필요하면 반대쪽에 \right. 처럼 점을 찍습니다.

6. 공백은 무시됩니다

  • 코드에 스페이스를 아무리 넣어도 결과에는 반영되지 않습니다. 보기 좋게 띄어 써도 됩니다
  • 일부러 공백을 넣으려면 \,(조금) \;(좀더) \quad \qquad(많이)
  • 한글·영어 문장을 넣으려면 \text{여기에} — 안 그러면 글자가 다 기울어집니다

7. 이 페이지의 "빠른 입력" 문법

KaTeX를 모를 때 쓰는 임시 표기법입니다. 왼쪽처럼 적으면 오른쪽 KaTeX 코드로 바꿔줍니다.
⚠️
딱 두 가지 규칙만 알아두세요.
① 괄호는 분수·루트에 들어가면 사라집니다. (a+b)/c → \frac{a+b}{c} 처럼요. 괄호를 화면에 보이게 하려면 분수 밖에 한 겹 더 쓰세요 — ((a+b))/c
② 띄어쓰기가 의미를 바꿉니다. 1/2(x+1) 은 \frac{1}{2(x+1)} 이지만, 한 칸 띄운 1/2 (x+1) 은 \frac{1}{2}(x+1) 입니다. sin(x)/x 도 붙여 써야 \frac{\sin(x)}{x} 가 됩니다.
🔤
헷갈리기 쉬운 표기 몇 가지
· sup inf 는 상한·하한입니다. 부분집합은 sub·subset, 포함은 supset 를 쓰세요.
· 무한대는 oo 또는 infty 입니다.
· dx dy dt 는 적분 변수로 보고 앞에 얇은 공백을 넣어줍니다.
· del 은 ∂(편미분), grad·nabla 는 ∇ 입니다.
✅
섞어 써도 됩니다. 빠른 입력 모드에서 \frac{a}{b} 같은 진짜 KaTeX 코드를 그대로 적어도 그대로 통과시킵니다. 아는 것부터 조금씩 KaTeX로 바꿔 쓰다 보면 어느새 다 쓰게 됩니다.

KaTeX와 LaTeX는 같은 문법인가요? 거의 같습니다. KaTeX는 웹에서 빠르게 그리려고 만든 것이라 LaTeX 수식 명령어의 대부분을 지원하지만, 잘 안 쓰는 일부 패키지 명령은 빠져 있습니다. 여기서 미리보기가 정상으로 나오면 KaTeX에서는 안전합니다.
