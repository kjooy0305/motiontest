⚡ 티타노마키아 (Titanomachy) — 신들의 전쟁
배경: 우주 창조 후 타이탄 vs 올림포스 신들
제우스가 크로노스에게 삼켜진 형제들을 구출 → 10년간 타이탄과 전쟁 → 키클로페스가 제우스에게 번개, 포세이돈에게 삼지창, 하데스에게 투명 투구 제작 → 올림포스 승리 → 타이탄은 타르타로스에 감금. 이후 기간토마키아(거인족과 전쟁)에서도 올림포스 신들이 승리.
🔥 프로메테우스의 불 — 인류에게 내려진 선물과 저주
주요 인물: 프로메테우스, 제우스, 에피메테우스, 판도라
프로메테우스가 신들의 불을 훔쳐 인간에게 줌 → 분노한 제우스가 카우카소스 산에 쇠사슬로 묶어 독수리가 매일 간을 먹게 함(매일 재생) → 헤라클레스가 독수리 사살·해방. 제우스는 복수로 판도라(최초의 여성)를 창조 → 에피메테우스에게 보냄 → 판도라가 항아리 열어 질병·노화·악 방출, 희망만 남음.
🌸 페르세포네와 계절의 탄생
주요 인물: 페르세포네, 하데스, 데메테르
페르세포네가 꽃을 따다 하데스에게 납치 → 데메테르가 슬픔에 빠져 농업 포기 → 기근·가뭄 → 제우스 중재 → 페르세포네가 석류 씨앗 6알을 먹었으므로 1년의 절반(6개월)은 저승에 머물러야 함 → 페르세포네가 지상에 있는 봄·여름, 저승에 있는 가을·겨울 = 계절의 기원.
🏺 트로이 전쟁 (Trojan War)
호메로스의 일리아스 · 약 10년 전쟁
에리스(불화의 여신)가 황금 사과 투척("가장 아름다운 자에게") → 헤라·아테나·아프로디테 다툼 → 파리스의 심판: 아프로디테 선택(스파르타 왕비 헬레네 얻게 해줌) → 파리스가 헬레네 납치 → 그리스 연합군 결성 → 트로이 포위 10년 → 아킬레우스·헥토르·파리스 모두 전사 → 오디세우스의 목마로 트로이 함락.
🎵 오르페우스와 에우리디케
사랑과 상실의 비극
음악의 천재 오르페우스가 아내 에우리디케를 독사에 잃음 → 저승 방문, 리라 연주로 케르베로스·카론·페르세포네·하데스 모두 눈물 흘림 → 조건부 귀환: "지상에 도착하기 전 절대 뒤돌아보지 말 것" → 마지막 순간 참지 못하고 돌아봄 → 에우리디케 영구히 저승으로 → 절망한 오르페우스는 여자를 거부 → 마이나데스들에게 찢겨 죽음. 그의 머리는 노래하며 바다를 떠돌았다.
🌊 오디세이아 (Odysseia) — 10년의 귀향
호메로스의 오디세이아
트로이 전쟁 승리 후 오디세우스의 귀향 모험: 키콘족 약탈 → 로토파고이 섬 → 폴리페모스(외눈박이 거인) 눈 찌르기 → 아이올로스 바람 주머니 → 라이스트리곤인(식인 거인) → 키르케 마법사 섬(1년) → 저승 방문 → 사이렌 통과(귀 막기) → 스킬라와 카립디스 → 헬리오스 소 사건 → 칼립소의 섬 7년 → 파이아케스 도움으로 이타카 귀환 → 구혼자 100여 명 활로 척살.
🏺 황금 양털 원정 (Argonautica)

🗿 나르키소스와 에코

💰 미다스 왕의 황금 손
탐욕과 대가
디오니소스의 스승 실레노스를 호대접 → 소원 한 가지 허락 → "손에 닿는 모든 것이 황금이 되길" → 음식·물·딸까지 황금으로 변해 비극 → 소원 취소 간청 → 팍톨로스 강에 씻어 황금손 사라짐. 이후 판vs아폴론 음악 대결에서 판 편 → 아폴론이 당나귀 귀로 변신.
🌹 에로스와 프시케
사랑·호기심·구원의 신화
인간 공주 프시케의 아름다움이 아프로디테를 능가 → 아프로디테가 에로스에게 저주 명령 → 에로스가 프시케에게 반함 → 비밀 결혼(어둠 속, 얼굴 불가) → 언니들의 꼬드김 → 촛불로 에로스 확인 → 에로스 상처·도주 → 아프로디테의 4가지 시련(씨 분류·황금 양털·저승 물·아름다움 상자) → 프시케 극복 → 에로스 구출 → 제우스 승인으로 불사 획득·결혼.
🏛️ 시시포스의 형벌
헛된 노동·부조리의 상징
교활한 왕 시시포스가 죽음의 신 타나토스를 쇠사슬로 묶어 한동안 세상에 죽음이 없었음 → 제우스 개입·해방 → 다시 한 번 아내에게 장례 없이 보내달라 부탁 → 하데스에게 "잠시 지상에 다녀오겠다" 거짓말 → 탈출 성공 · 결국 붙잡혀 영원한 형벌: 거대한 바위를 산 정상까지 밀어올리면 굴러 내려옴 — 영원 반복.
🌺 히아킨토스의 죽음
히아신스꽃의 기원
아폴론이 사랑한 미소년 히아킨토스 → 원반던지기 중 서풍의 신 제피로스가 질투로 바람을 바꿈 → 원반이 히아킨토스 머리를 강타 → 사망 → 피에서 히아신스꽃 피어남 → 꽃잎에 "Ai Ai"(슬픔의 외침) 문양.
🦅 이카로스의 비행
오만과 추락의 경고
발명가 다이달로스가 크레타에 감금 → 밀랍 날개 제작 → 아들 이카로스에게 "너무 낮으면 파도에 젖고, 너무 높으면 태양에 녹는다" 경고 → 이카로스가 흥분하여 너무 높이 날아오름 → 밀랍 녹아 추락·익사 → 이카리아 해 유래. 다이달로스는 시칠리아로 안전하게 탈출.
🕸️ 아라크네의 오만
거미의 기원
직녀 아라크네가 "아테나보다 베를 잘 짠다"고 자랑 → 아테나가 노파로 변장해 경고 → 무시 → 대결: 아라크네의 직물에 신들의 불륜·비행이 완벽히 수놓임 → 아테나 분노 → 아라크네의 직물을 찢고 저주 → 아라크네 자살 → 아테나가 불쌍히 여겨 거미로 변신 → 영원히 실을 짬.
