초급 <!DOCTYPE> <html> <head> <body> HTML 기본 구조

모든 HTML 문서는 아래 기본 골격으로 시작해요. DOCTYPE은 브라우저에게 "HTML5 문서야!"라고 알려주는 선언이에요.

HTML
<!-- 항상 맨 위에! DOCTYPE 선언 -->
<!DOCTYPE html>
<html lang="ko">

<head>
  <!-- 브라우저용 정보 (화면에 보이지 않음) -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>내 첫 웹페이지</title>
</head>

<body>
  <!-- 화면에 실제로 보이는 내용 -->
  <h1>안녕하세요!</h1>
  <p>첫 번째 HTML 페이지예요.</p>
</body>

</html>
기억하세요! head 안에는 보이지 않는 설정, body 안에는 화면에 보이는 내용을 넣어요. lang="ko"는 한국어 문서라고 알려줘요.

초급 <a> 링크 (앵커) 태그

href에 주소를 적어요. target="_blank"를 쓰면 새 탭에서 열려요. #으로 시작하면 같은 페이지 안에서 이동해요.

HTML
<!-- 외부 링크 -->
<a href="https://google.com">구글로 이동</a>

<!-- 새 탭에서 열기 -->
<a href="https://google.com" target="_blank" rel="noopener">
  새 탭으로 열기
</a>

<!-- 이메일 -->
<a href="mailto:hello@example.com">이메일 보내기</a>

<!-- 전화 -->
<a href="tel:010-1234-5678">전화하기</a>

<!-- 페이지 내 이동 -->
<a href="#section1">섹션1로 이동</a>
<div id="section1">여기로 이동됨!</div>
보안 팁! target="_blank"를 쓸 때 rel="noopener noreferrer"를 함께 쓰면 보안에 좋아요.
초급 <img> <figure> <figcaption> 이미지 태그

src에 이미지 경로, alt에 이미지가 안 보일 때 표시할 설명을 써요. alt는 접근성과 SEO를 위해 꼭 써야 해요!

HTML
<!-- 기본 이미지 -->
<img src="cat.jpg" alt="귀여운 고양이" width="300">

<!-- 캡션 있는 이미지 -->
<figure>
  <img src="cat.jpg" alt="귀여운 고양이">
  <figcaption>그림 1. 냥냥이 사진</figcaption>
</figure>

<!-- 반응형 이미지 (화면 크기별 다른 이미지) -->
<picture>
  <source media="(max-width:600px)" srcset="small.jpg">
  <source media="(max-width:1200px)" srcset="medium.jpg">
  <img src="large.jpg" alt="풍경">
</picture>
성능 팁! loading="lazy"를 추가하면 스크롤 내릴 때 이미지를 불러와서 초기 로딩이 빨라져요.

초급 <div> <span> div · span 컨테이너

div는 줄 전체를 차지하는 블록 컨테이너, span은 텍스트 일부에 쓰는 인라인 컨테이너예요. CSS와 JS를 연결할 때 많이 써요.

HTML
<!-- div: 블록 (줄 전체 차지) -->
<div class="box">
  이 안에 여러 요소를 묶어요.
</div>

<!-- span: 인라인 (텍스트 안에서 사용) -->
<p>제 이름은 
  <span style="color:red">홍길동</span>
입니다.</p>

<!-- id: 페이지에서 유일한 이름 -->
<div id="header">헤더 영역</div>

<!-- class: 여러 요소에 같은 이름 붙이기 -->
<div class="card">카드 1</div>
<div class="card">카드 2</div>
블록 vs 인라인: div는 혼자 한 줄을 차지해요. span은 텍스트 흐름 안에서 일부만 감싸요. CSS display 속성으로 바꿀 수도 있어요.

비디오, 오디오, 외부 페이지를 삽입할 수 있어요. controls 속성으로 재생 컨트롤러를 보여줘요.

HTML

<iframe

중급 <header> <nav> <main> <section> <article> <footer> 시멘틱 태그 (의미있는 구조)

div 대신 의미있는 태그를 쓰면 코드가 읽기 쉽고 검색엔진, 스크린리더도 내용을 잘 이해해요. HTML5에서 추가된 핵심 태그들이에요.

HTML
<header>          <!-- 페이지/섹션의 머리 부분 -->
  <nav>            <!-- 내비게이션 메뉴 -->
    <a href="/">홈</a>
    <a href="/about">소개</a>
  </nav>
</header>

<main>            <!-- 페이지의 핵심 콘텐츠 (1개만!) -->
  <section>      <!-- 주제별 묶음 -->
    <h2>최신 글</h2>

    <article>    <!-- 독립적인 콘텐츠 (뉴스, 블로그 글) -->
      <h3>블로그 글 제목</h3>
      <p>본문 내용...</p>
    </article>
  </section>

  <aside>         <!-- 사이드바, 관련 링크 -->
    광고 또는 관련 글
  </aside>
</main>

<footer>          <!-- 페이지 하단 (저작권, 연락처) -->
  © 2024 My Site
</footer>
시멘틱의 장점: 검색엔진이 내용을 더 잘 파악해 SEO에 유리하고, 시각장애인용 스크린리더가 페이지 구조를 쉽게 안내할 수 있어요.
중급 <meta> <link> <script> 메타 태그 & 리소스 연결

head 안에서 브라우저와 검색엔진에게 정보를 알려줘요. og 태그를 쓰면 카카오톡·슬랙 공유 시 미리보기가 예쁘게 나와요.

HTML
<head>
  <!-- 필수 기본 -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="페이지 설명 (검색 결과에 표시)">

  <!-- 오픈 그래프 (SNS 공유 미리보기) -->
  <meta property="og:title" content="페이지 제목">
  <meta property="og:description" content="페이지 설명">
  <meta property="og:image" content="https://example.com/thumb.jpg">
  <meta property="og:url" content="https://example.com">

  <!-- CSS 연결 -->
  <link rel="stylesheet" href="style.css">

  <!-- JS 연결 (defer: HTML 파싱 후 실행) -->
  <script src="app.js" defer></script>
</head>
defer vs async: defer는 HTML 파싱 끝나고 순서대로 실행, async는 다운로드 즉시 실행(순서 보장 안 됨). 보통 defer를 써요.
고급 data-* 속성 커스텀 데이터 속성

HTML 요소에 data-로 시작하는 속성을 만들어 데이터를 저장할 수 있어요. JS에서 dataset으로 읽어요.

HTML
<!-- HTML에서 데이터 저장 -->
<button
  data-user-id="42"
  data-action="delete"
  data-confirm-msg="정말 삭제할까요?"
  onclick="handleClick(this)"
>삭제</button>

<div class="product"
     data-price="15000"
     data-category="food">
  상품명
</div>
JavaScript
function handleClick(btn) {
  // data-user-id → dataset.userId (카멜케이스로 변환됨)
  const userId = btn.dataset.userId;   // "42"
  const action = btn.dataset.action;   // "delete"
  const msg = btn.dataset.confirmMsg;  // "정말 삭제할까요?"

  if(confirm(msg)) {
    console.log(`${action} user ${userId}`);
  }
}

// CSS에서도 사용 가능:
// [data-category="food"] { background: green; }
활용 예시: 상품 ID, 필터링 카테고리, 애니메이션 옵션 등 JS에 전달할 데이터를 HTML에 깔끔하게 저장할 때 써요.
고급 aria-* role tabindex 웹 접근성 (ARIA)

시각장애인이 스크린리더로 웹을 사용할 때 필요한 정보를 제공해요. role로 역할을, aria-*로 상태와 관계를 표현해요.

HTML
<!-- 버튼 역할 + 레이블 -->
<button aria-label="메뉴 열기" aria-expanded="false">
  ☰
</button>

<!-- 내비게이션 역할 명시 -->
<nav aria-label="주 메뉴"> ... </nav>

<!-- 라이브 영역: 동적으로 변하는 내용 알림 -->
<div aria-live="polite" id="status">
  파일 업로드 완료!
</div>

<!-- 키보드 포커스 순서 -->
<div tabindex="0" role="button"
     aria-label="좋아요"
     onkeypress="if(event.key==='Enter')like()"
     onclick="like()">
  ❤️ 좋아요
</div>

<!-- 숨김 텍스트 (스크린리더만 읽음) -->
<span class="sr-only">현재 페이지: 홈</span>
tabindex 규칙: 0이면 자연스러운 탭 순서에 포함, -1이면 탭으로는 못 가지만 JS로 포커스 가능, 양수(1,2,3...)는 순서 지정 (잘 안 써요).
고급 <canvas> Canvas — 2D 그래픽

JS로 픽셀 단위의 그래픽을 그릴 수 있어요. 게임, 차트, 애니메이션에 자주 써요. getContext('2d')로 2D 그리기를 시작해요.

HTML
<canvas id="myCanvas" width="400" height="200"></canvas>
JavaScript
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// 사각형 그리기
ctx.fillStyle = '#60a5fa';
ctx.fillRect(10, 10, 150, 80);     // x, y, width, height

// 원 그리기
ctx.beginPath();
ctx.arc(250, 60, 40, 0, Math.PI * 2); // x, y, 반지름, 시작각, 끝각
ctx.fillStyle = '#34d399';
ctx.fill();

// 텍스트 그리기
ctx.font = '20px Arial';
ctx.fillStyle = '#fff';
ctx.fillText('Hello Canvas!', 50, 60);

// 애니메이션 루프
let x = 0;
function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillRect(x, 80, 30, 30);
  x = (x + 2) % canvas.width;
  requestAnimationFrame(animate);
}

고급 <template> <slot> Template & Web Components

template 태그 안 내용은 렌더링되지 않아요. JS로 복제해서 써요. Shadow DOM과 함께 쓰면 캡슐화된 웹 컴포넌트를 만들 수 있어요.

HTML
<!-- 템플릿 정의 (화면에 안 보임) -->
<template id="card-tpl">
  <div class="card">
    <h3 class="card-title"></h3>
    <p class="card-body"></p>
  </div>
</template>

<div id="container"></div>
JavaScript
const tpl = document.getElementById('card-tpl');
const data = [
  { title: '제목 1', body: '내용 1' },
  { title: '제목 2', body: '내용 2' },
];

data.forEach(item => {
  // 템플릿 복제
  const clone = tpl.content.cloneNode(true);
  clone.querySelector('.card-title').textContent = item.title;
  clone.querySelector('.card-body').textContent = item.body;
  document.getElementById('container').appendChild(clone);
});
왜 쓰나요? innerHTML로 HTML 문자열을 동적으로 만드는 것보다 XSS 공격에 안전하고, 재사용 가능한 UI 조각을 만들기에 좋아요.
