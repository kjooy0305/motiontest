🎨 Blender — 인터페이스 완전 정복
Blender는 무료·오픈소스 3D 창작 도구입니다. 모델링·스컬프트·애니메이션·렌더링·합성·비디오 편집까지 하나의 프로그램으로 처리합니다.
📋기본 정보
개발사Blender Foundation (비영리). 오픈소스 (GPL v3). 1994년 시작.
현재 버전Blender 4.x (2024~). LTS 버전은 2년 지원. 매 분기 신규 버전 출시.
플랫폼Windows, macOS, Linux. 64비트 전용. GPU: NVIDIA/AMD/Intel 모두 지원.
가격완전 무료. blender.org에서 다운로드.
주요 기능3D 모델링·스컬프트·애니메이션·리깅·파티클·시뮬레이션·렌더링(Cycles/EEVEE)·합성·그리스 펜슬·비디오 편집·지오메트리 노드
키맵 기본값이 페이지는 Blender 기본 키맵 (4.x) 기준. Industry Compatible 키맵은 일부 다름. Mac은 Ctrl→Cmd 치환.

💡알아두면 강력한 팁
  • F3 기능 검색이 최강. 단축키 모를 때 F3로 기능 이름 검색하면 바로 실행 가능. 검색 후 마우스 오른쪽 클릭으로 단축키 할당도 가능.
  • F9 마지막 작업 수정. 어떤 작업(압출·추가·Loop Cut 등) 직후 F9를 누르면 수치 조정 패널이 나타남.
  • G → Middle Mouse → 축 드래그. 이동 중 중간 마우스 버튼을 누르면 드래그 방향의 축으로 자동 잠금.
  • Alt + 클릭으로 루프 선택. 에디트 모드에서 Alt+클릭 하나로 루프 전체 선택.
  • Ctrl + R 스크롤 = 루프컷 개수. Ctrl+R 후 스크롤 휠로 루프 개수 조절.
  • Dyntopo는 스컬프트 전용. 편집 중 자동으로 폴리곤 추가·제거. 세밀한 부분에서 시작해 전체로 가는 Top-Down 방식에 적합.
  • Ctrl+A로 스케일 적용. 스케일이 1이 아닌 오브젝트는 물리 시뮬레이션·모디파이어에서 문제가 생길 수 있음.
  • Render Denoising 필수. Cycles에서 샘플을 낮춰도 OptiX/OIDN으로 노이즈 제거하면 빠른 렌더 가능.
  • Mirror 모디파이어 활용. 대칭 모델은 Clipping 켜고 Mirror 사용. 절반만 만들면 됨.
  • 연산 수치 직접 입력. G/R/S 후 숫자를 타이핑하면 정확한 값으로 이동 (예: G Z 2 Enter = Z축으로 2 이동).
