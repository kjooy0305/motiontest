🧱 Blockbench 완전 정리

개요Overview

Blockbench는 무료·오픈소스(GPL-3.0) 로우폴리 3D 모델링·텍스처링·애니메이션 편집기입니다. 마인크래프트 모델 제작의 사실상 표준 도구이며, 일반 게임 엔진용 모델 작업에도 쓰입니다.

실행 방법 3가지

  • 웹 앱 — blockbench.net/app. 설치 없이 브라우저에서 바로 사용. 주소창의 설치 버튼으로 PWA(앱처럼 설치)도 가능.
  • 데스크톱 앱 — Windows / macOS / Linux. 파일 시스템 직접 접근, 로컬 백업, 플러그인 개발에 유리.
  • 모바일 — 웹 앱이 터치 UI로 전환됨(UI 모드 설정으로 강제 전환 가능).
데스크톱 앱만 되는 것: 파일 경로 기억(Ctrl + S 덮어쓰기 저장), 로컬 백업 폴더, 개발자 도구, 일부 파일 연동 플러그인.

화면 구성

  • 메뉴 바 — 파일·편집·변환·메쉬·UV·이미지·애니메이션·도구·보기·도움말
  • 모드 탭 — 편집 / 칠하기 / 애니메이션 / 디스플레이 (포맷에 따라 표시되는 모드가 다름)
  • 메인 툴바 — 현재 모드의 도구와 슬라이더
  • 뷰포트 — 3D 작업 영역. 우하단 오빗 기즈모로 시점 회전·측면 전환
  • 좌·우 사이드바 — 패널(아웃라이너·UV·텍스처·색상·타임라인 등). Ctrl + B로 접기
  • 상태 바 — 포맷 아이콘, 모델 식별자, 지금 누르면 되는 보조키 힌트, 경고, FPS

좌표계와 단위

  • 축: X = 너비, Y = 높이, Z = 길이. 원점은 0, 0, 0.
  • 기본 단위 1 = 텍스처 1픽셀 = 블록의 1/16.
  • 격자 스냅 단위는 환경 설정 › 스냅에서 조절. 보조키를 누르면 다른 단위로 스냅 (Shift·Ctrl·Ctrl + Shift 각각 별도 값).
  • 자바 블록 모델은 -16 ~ 32 범위 제한이 있음 — 크기 제한 비활성화 설정으로 해제 가능(단 게임에서 깨질 수 있음).

파일과 안전장치

  • .bbmodel — Blockbench 프로젝트 파일(JSON). 텍스처를 안에 포함(임베드)할 수 있음.
  • .bbkeymap — 단축키 세트 내보내기/가져오기 파일.
  • 자동 백업 — 기본 10분 간격(환경 설정 › 앱에서 주기·보존 기간 변경). 도움말 › 백업 파일 보기로 복구.
  • 복구 지점 — 브라우저/앱이 강제 종료돼도 다음 실행 시 복구 제안.
  • 모델 저장(Ctrl + S)은 게임용 포맷으로 내보내기, 프로젝트 저장(Ctrl + Alt + S)은 .bbmodel 저장 — 둘은 다릅니다.

핵심 기능 한눈에

  • 박스 모델링 — 큐브 단위 편집, 인플레이트/디플레이트, 정점 스냅
  • 메쉬 모델링 — 압출·인셋·루프컷·정점 병합·나이프·솔리디파이
  • UV 편집 — 박스 UV / 페이스별 UV, 자동 UV, UV 잇기(seam)
  • 텍스처 페인팅 — 브러시·채우기·그라데이션·레이어·팔레트
  • 이미지 편집 — 밝기/채도/커브/색 반전, 채널 분리, 잘라내기
  • 애니메이션 — 키프레임, 그래프 에디터, Molang 수식, IK 베이크
  • 디스플레이 모드 — 자바 아이템의 손·머리·GUI 등 슬롯별 배치
  • 렌더/공유 — 스크린샷, GIF 녹화, 타임랩스, Sketchfab 업로드, 링크 공유
  • 확장 — 플러그인 스토어, 테마, 다국어(한국어 포함), 공동 편집 세션
이 문서의 단축키 값은 Blockbench 기본 설정 기준입니다. 사용자가 바꾼 단축키나 Blender/Maya 프리셋을 쓰는 경우 실제 키가 다릅니다. 앱에서 확인하려면 메뉴 항목에 마우스를 올리거나 파일 › 사용자 설정 › 단축키 설정을 여세요.

프로젝트 포맷Formats

새 모델을 만들 때 고르는 포맷이 사용 가능한 모드·요소·내보내기 방식을 전부 결정합니다. 나중에 파일 › 프로젝트 변환으로 바꿀 수 있습니다.

포맷별 제약 예시 — 자바 블록/아이템은 큐브만 허용(회전은 축 하나에 22.5° 배수), 베드락 엔티티는 애니메이션·본 계층 지원, 자유 모델은 제약 없이 메쉬·회전 자유(게임 엔진·렌더용).

모드 & 도구Modes & Tools

모드 탭으로 작업 종류를 바꾸면 툴바와 사이드바 패널이 함께 바뀝니다. 기본 단축키에는 모드 전환 키가 없고, Blender 프리셋에서만 1~4가 할당됩니다(직접 지정 가능).

모드편집 Edit

  • 요소 추가·이동·크기·회전, 회전 중심(피벗) 설정, 메쉬 편집, UV 매핑.
  • 메쉬 편집 시 편집 모드(정점 / 모서리 / 면)를 툴바에서 전환.
  • 비율 편집(소프트 선택)과 미러 모델링으로 대칭 작업을 자동화.

모드칠하기 Paint

  • 3D 모델 표면이나 UV 에디터에서 텍스처를 직접 그림. 레이어·팔레트 지원.
  • Alt를 누르고 있으면 임시로 색 추출, Shift는 직선 긋기.
  • 기본값에서 Shift(마우스 프리셋은 우클릭)로 보조 색을 칠함.

모드애니메이션 Animate

  • 타임라인·키프레임으로 본 단위 애니메이션 제작. 그래프 에디터로 보간 곡선 편집.
  • 키프레임 값에 Molang 수식을 직접 입력할 수 있음.
  • 이펙트 애니메이터로 파티클·사운드·타임라인 스크립트 배치(베드락).

모드디스플레이 Display

  • 자바 아이템/블록 모델이 손·머리·바닥·액자·GUI 슬롯에서 어떻게 보일지 배치.
  • 슬롯별 위치·회전·크기를 저장하고 프리셋으로 재사용.

도구 목록

Space 교환 도구 — 이동 ↔ 크기 조정처럼 짝지어진 도구를 번갈아 전환합니다(더블클릭으로도 동작, 설정에서 끌 수 있음).

패널

메뉴별 기능Menu Reference

메뉴 바 전체를 그대로 옮긴 목록입니다. 오른쪽에 기본 단축키가 있는 항목은 그 키로 바로 실행됩니다. 회색으로 표시된 항목은 현재 포맷·모드에서만 나타납니다.

단축키 전체Keybindings

기본값으로 지정돼 있는 단축키 개입니다. [Shift]처럼 대괄호로 묶인 보조키는 있어도 되고 없어도 되는(무시되는) 키입니다.

바꾸는 곳 — 파일 › 사용자 설정 › 단축키 설정. 검색해서 찾고, 키를 눌러 지정하고, .bbkeymap으로 내보내 다른 PC와 공유합니다. 충돌하면 목록에 빨간 표시가 뜹니다. 단축키가 없는 기능도 대부분 여기서 직접 지정할 수 있습니다.
보조키 변형 — 같은 단축키에 Shift/Ctrl/Alt를 더하면 동작이 살짝 달라지는 항목들이 있습니다. 아래 목록에서 파란 줄로 표시했습니다.

단축키 없이 쓰는 두 가지 지름길

  • F 액션 컨트롤 — 모든 명령을 이름으로 검색해 실행. 단축키를 외우지 않아도 되는 가장 빠른 길이며, 플러그인 설치도 여기서 됩니다.
  • 우클릭 메뉴 — 뷰포트·아웃라이너·텍스처·타임라인 각각 전용 맥락 메뉴가 있어 해당 상황에 필요한 기능만 모여 있습니다.

선택 방법

  • 클릭 하나 선택 / Ctrl + 클릭 여러 개 추가
  • 아웃라이너에서 Shift + 클릭 — 범위 선택
  • 뷰포트에서 Shift + 클릭 — 그룹(본) 전체 선택
  • 메쉬에서 Alt + 클릭 — 모서리 루프 선택
  • Ctrl + Shift + 좌클릭 드래그 — 영역(박스) 선택
  • UV 패널에서 Ctrl + 클릭 — 그 UV 조각을 쓰는 요소 선택
  • Ctrl + A 모두 선택 / Ctrl + I 선택 반전 / Ctrl + F 조건으로 선택
  • I 선택만 남기고 전부 숨기기 — 복잡한 모델에서 특히 유용

카메라 시점 (숫자 키패드)

  • Numpad 1 첫 각도(정면) · Numpad 5 원근/정사영 전환
  • Numpad 8 위 · Numpad 2 아래
  • Numpad 4 남 · Numpad 6 북 · Numpad 7 동 · Numpad 9 서
  • 뷰포트 우클릭 › 각도에서 아이소메트릭(2:1 / 30°) 프리셋 사용, 현재 각도 저장도 가능
  • 선택 중심 보기 — Shift 추가하면 회전만, Ctrl 추가하면 화면에 맞게 확대
  • 뷰포트 우클릭 › 사면 보기로 정면·측면·위·투시 4분할

환경 설정에서 챙길 것Preferences

파일 › 사용자 설정 › 설정. 항목이 많지만 작업 속도를 실제로 바꾸는 것들만 골랐습니다.

일반 · 인터페이스

  • 언어 — 한국어 지원. 라벨 일부는 영문으로 남아 있음.
  • 인터페이스 크기 / UI 모드 — 고해상도 화면이나 태블릿에서 조절.
  • 상태바 보조키 제안 — 지금 Shift·Ctrl을 누르면 무엇이 달라지는지 하단에 표시. 켜 두면 학습에 도움.
  • 외곽선 X-Ray — 가려진 요소의 선택 윤곽을 뚫고 보여줌.
  • 스트리머 모드 — 미공개 프로젝트 제목을 화면에서 가림.

편집 · 스냅

  • 격자 크기 / Shift·Ctrl·Ctrl+Shift 단위 — 보조키별 스냅 값. 0.5픽셀 작업이 잦으면 여기부터.
  • 실행 취소 한계 — 기본값보다 늘리면 긴 작업에서 안전.
  • 정점 병합 거리 — Shift + M 병합이 너무 붙거나 안 붙을 때.
  • 중심에서 크기 조정 — 큐브를 양쪽으로 동시에 키움.
  • 크기 제한 비활성화 — 자바 모델 범위 제한 해제(게임에서 잘릴 수 있음).

칠하기

  • 투명한 픽셀 뒤로 그리기 — 껐다 켜는 것만으로 결과가 크게 달라짐.
  • 브러시 옆으로 제한 — 3D에서 칠할 때 옆면으로 새는 것 방지.
  • 브러시 크기·불투명 수정 키 — 어떤 보조키로 브러시를 조절할지 지정.
  • 스타일러스펜으로만 칠하기 — 태블릿에서 손바닥 오작동 방지.

뷰포트 · 격자 · 내보내기

  • 밝기 / 셰이딩 / 시야각(FOV) / 안티에일리어싱 — 렌더 느낌과 성능.
  • 옆면 렌더 — 뒷면까지 보이게 할지(컬링 확인용).
  • 격자류 — 작은 격자·블록 격자·픽셀 격자·바닥면을 개별 토글.
  • 최소화된 내보내기 / 텍스처 임베드 / 모델 내보내기 크기 — 산출물 형태.
  • 백업 주기·보존 기간, 자동 업데이트, 하드웨어 가속(데스크톱).
설정과 단축키는 프로필로 묶어 저장할 수 있습니다(파일 › 사용자 설정 › 프로필). 작업 종류별로 다른 세팅을 오갈 때 유용합니다.

실전 팁Tips

공식 가이드와 앱 동작에서 확인한, 작업 속도에 실제로 영향을 주는 것들만 모았습니다.

입력 · 슬라이더

  • 사이드바의 숫자 슬라이더는 드래그, 화살표 클릭, 직접 입력이 모두 됩니다.
  • 더블클릭하면 기본값으로 초기화.
  • 계산식 입력 가능 — 8/3, 2+0.5 같은 수식과 Molang 문법을 그대로 씁니다.
  • 여러 요소를 선택한 상태에서 슬라이더를 움직이면 상대값으로 함께 이동합니다.

모델링

  • Z-파이팅(면이 깜빡임)은 같은 평면에 겹친 면이 원인 — 살짝 띄우거나 부풀리기(Inflate) 값을 아주 작게 주면 해결.
  • 부풀리기는 UV를 유지하면서 크기를 키웁니다. 크기 조정과 달리 텍스처가 안 어긋남.
  • 회전 중심 도구(P)로 관절 위치를 먼저 잡아야 애니메이션이 자연스럽습니다.
  • 꼭짓점 맞춤(X) — 큐브의 한 꼭짓점을 다른 큐브 꼭짓점에 정확히 붙임.
  • 뒤집기는 이름의 left/right를 자동으로 바꿔 줍니다(대칭 파트 만들 때).
  • 참조용 이미지(블루프린트)를 뷰포트에 깔고 그 위에서 모델링할 수 있습니다.

덜 알려진 단축키

  • Ctrl + Tab 열린 프로젝트 탭 순환 (Shift 추가 시 역순)
  • Ctrl + Shift + G 선택 항목을 새 그룹으로 감싸기
  • I 선택만 남기고 숨기기 · Z 텍스처/단색/와이어프레임 전환
  • , . 타임라인 1프레임 앞뒤 이동
  • Alt + Delete 면만 지우고 정점·모서리는 남기기
  • Shift + Q 키프레임을 기본값으로 강제 생성
  • UV 관련 버튼에 Shift를 더하면 모든 면에 적용
  • Ctrl + Shift + C/V 전체(모든 요소·채널) 복사·붙여넣기

애니메이션

  • 키프레임 값 칸에 Molang 수식을 넣으면 절차적 움직임을 만들 수 있습니다(Math.sin(query.anim_time*90) 형태).
  • 그래프 에디터(F3)에서 베지어 핸들로 가감속을 다듬습니다.
  • 애니메이션 최적화로 불필요한 키프레임을 정리, IK 베이크로 역운동학을 일반 키프레임으로 변환.
  • 애니메이션 좌우 반전·애니메이터 재지정으로 다른 모델에 재활용.
  • 어니언 스킨으로 앞뒤 프레임을 겹쳐 보며 타이밍 조정.

내보내기 · 공유

  • 게임용 모델 저장과 작업용 프로젝트 저장을 구분해서 습관 들이기.
  • 3D 범용 포맷: glTF · OBJ · FBX · Collada(dae) · STL.
  • 공유하기로 짧은 링크 생성, Sketchfab에 직접 업로드 가능.
  • 렌더용 스크린샷은 고급 스크린샷에서 해상도·배경 투명도를 지정.
  • 작업 과정은 타임랩스, 움직임은 GIF로 녹화.
