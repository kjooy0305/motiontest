user@terminal:~$
📁 기본 파일 & 디렉토리
파일 시스템 탐색, 생성, 복사, 삭제 등 가장 자주 쓰이는 명령어 모음
01 탐색 (Navigation)
pwd
현재 작업 디렉토리 경로 출력
Print Working Directory. 내가 지금 어디 있는지 확인.
$ pwd → /home/user/projects
ls
디렉토리 내용 목록 출력
-l 상세 정보 · -a 숨김파일 포함 · -h 파일 크기 읽기 쉽게 · -t 시간순 정렬
$ ls -lah → 숨김 포함 전체 목록 (크기 단위 표시)
cd [경로]
디렉토리 이동
~ 홈 디렉토리 · .. 상위 폴더 · - 이전 디렉토리로 돌아가기
$ cd ~/Documents  |  $ cd ..  |  $ cd -
tree [경로]
디렉토리 구조를 트리 형태로 시각화
-L 2 깊이 2단계까지 · -I node_modules 특정 폴더 제외
$ tree -L 2 -I node_modules
02 파일 생성 & 보기
cat [파일]
파일 내용을 터미널에 출력
여러 파일을 연결(concatenate)하는 게 원래 용도. -n 줄 번호 표시.
$ cat file.txt  |  $ cat -n file.txt
less [파일]
파일을 페이지 단위로 스크롤하며 보기
↑↓ 스크롤 · Space 다음 페이지 · /키워드 검색 · q 종료. 대용량 로그 파일에 적합.
head [파일]
파일 앞부분 출력 (기본 10줄)
-n 20 앞 20줄 출력. 로그 시작 부분 확인에 유용.
$ head -n 20 app.log
tail [파일]
파일 뒷부분 출력 (기본 10줄)
-f 실시간 감시 (로그 모니터링 필수). -n 50 마지막 50줄.
$ tail -f /var/log/nginx/access.log
touch [파일]
빈 파일 생성 / 타임스탬프 갱신
파일이 없으면 새로 만들고, 있으면 수정 시간만 업데이트.
$ touch index.html style.css
echo "텍스트"
텍스트 출력 또는 파일에 쓰기
> 파일 덮어쓰기 · >> 파일에 이어 쓰기.
$ echo "Hello" > file.txt  |  $ echo "줄 추가" >> file.txt
03 복사 · 이동 · 삭제
cp 원본 대상
파일/디렉토리 복사
-r 디렉토리 재귀 복사 · -p 권한/타임스탬프 보존 · -v 진행 상황 출력.
$ cp -r src/ backup/  |  $ cp -p config.env config.env.bak
mv 원본 대상
파일/디렉토리 이동 또는 이름 변경
같은 디렉토리 내 이동은 사실상 이름 바꾸기. -i 덮어쓰기 전 확인.
$ mv old.txt new.txt  |  $ mv *.log /tmp/logs/
rm [파일]
파일/디렉토리 삭제
-r 디렉토리 재귀 삭제 · -f 확인 없이 강제 삭제 · -i 삭제 전 확인.
rm -rf 는 복구 불가. 신중하게 사용할 것!
$ rm file.txt  |  $ rm -ri ./temp/
mkdir [폴더명]
디렉토리 생성
-p 중간 경로까지 한 번에 생성.
$ mkdir -p src/components/ui
rmdir [폴더명]
빈 디렉토리만 삭제
내용이 있으면 실패. 내용 포함 삭제는 rm -r 사용.
04 파일 찾기
find [경로] [조건]
파일/디렉토리 검색
-name "*.js" 이름 패턴 · -type f/d 파일/폴더 · -mtime -7 7일 이내 수정 · -size +10M 10MB 초과.
$ find . -name "*.log" -mtime -3
$ find /home -type f -size +100M
locate [키워드]
파일 위치 빠르게 검색 (인덱스 기반)
find보다 훨씬 빠름. 단, DB 갱신이 필요: sudo updatedb.
$ locate nginx.conf
which [명령어]
명령어의 실행 파일 경로 출력
여러 버전이 설치되어 있을 때 어느 게 실행되는지 확인.
$ which python3 → /usr/bin/python3
whereis [명령어]
실행파일·소스·매뉴얼 경로 모두 표시
which보다 넓은 범위를 검색.
$ whereis git → git: /usr/bin/git /usr/share/man/man1/git.1.gz
05 디스크 & 시스템 정보
df -h
디스크 사용량 확인
-h 사람이 읽기 쉬운 단위(GB, MB). 각 파티션의 용량·사용량·여유 공간 표시.
$ df -h → /dev/sda1: 50G 중 32G 사용 (68%)
du -sh [경로]
디렉토리/파일 용량 확인
-s 합계만 · -h 읽기 쉬운 단위 · --max-depth=1 하위 1단계.
$ du -sh ~/Downloads/* | sort -h
uname -a
시스템 정보 출력 (OS, 커널, 아키텍처)
-r 커널 버전만 · -m 아키텍처만(x86_64, arm64 등).
uptime
시스템 가동 시간 및 부하 평균 확인
load average: 1분·5분·15분 평균 CPU 부하. 코어 수보다 낮으면 정상.
free -h
메모리 사용량 확인
total / used / free / buff/cache / available 표시. available이 실제 사용 가능한 메모리.
📝 텍스트 처리 & 검색
파일 내용 검색, 변환, 필터링 — 파이프(|)와 조합하면 강력해짐
01 grep — 텍스트 검색의 핵심
grep "패턴" 파일
파일에서 패턴(문자열/정규식)이 있는 줄 출력
Global Regular Expression Print. 터미널에서 가장 많이 쓰는 명령어 중 하나.
$ grep "error" app.log
grep -r "패턴" 경로
디렉토리 전체를 재귀 검색
-n 줄 번호 · -i 대소문자 무시 · -l 파일명만 출력 · -v 패턴 없는 줄 출력.
$ grep -rn "TODO" ./src/
grep -E "정규식"
확장 정규표현식(ERE) 사용
. 임의 문자 · * 0개 이상 · + 1개 이상 · | OR · ^ 줄 시작 · $ 줄 끝.
$ grep -E "error|warn|fail" app.log
grep -c "패턴"
패턴이 일치하는 줄 수만 출력
파일별 에러 개수 집계에 유용.
$ grep -c "ERROR" server.log → 42
02 sed — 텍스트 치환 & 변환
sed 's/원본/대체/'
줄에서 첫 번째 매칭 문자열 치환
Stream Editor. 파일을 직접 수정하지 않고 출력만 바꿈.
$ sed 's/foo/bar/' file.txt
sed 's/원본/대체/g'
줄 전체에서 모든 매칭 치환 (global)
-i 파일 직접 수정 · -i.bak 백업 파일 만들고 수정.
$ sed -i 's/localhost/0.0.0.0/g' config.json
sed -n '5,10p'
5번~10번 줄만 출력
-n 자동 출력 억제. p로 명시한 줄만 출력.
$ sed -n '5,10p' file.txt
sed '/패턴/d'
패턴이 있는 줄 삭제
주석 줄 제거, 빈 줄 제거 등에 활용.
$ sed '/^#/d' config.txt  # 주석 줄 제거
03 awk — 열(컬럼) 처리
awk '{print $1}'
각 줄의 첫 번째 열(컬럼) 출력
$0 전체 줄 · $1 첫 번째 열 · $NF 마지막 열. 기본 구분자는 공백.
$ ls -l | awk '{print $9}'  # 파일명만
awk -F, '{print $2}'
구분자를 쉼표(,)로 지정해 두 번째 열 출력
CSV 파싱에 자주 활용. -F 로 원하는 구분자 지정 가능.
$ awk -F, '{print $1, $3}' data.csv
awk '/패턴/ {print}'
패턴과 일치하는 줄만 출력
grep보다 다양한 조건 처리 가능 (숫자 비교, 다중 조건 등).
$ awk '/ERROR/ {print NR": "$0}' app.log
awk '{sum+=$1} END{print sum}'
첫 번째 열 값들의 합계 계산
집계·통계 처리에 강력. END는 파일을 다 읽은 후 실행되는 블록.
$ awk '{sum+=$5} END{print "total:", sum}' sales.txt
04 정렬 · 중복 제거 · 집계
sort [파일]
줄 단위 정렬 (기본: 알파벳 오름차순)
-r 내림차순 · -n 숫자 정렬 · -k2 2번째 열 기준 · -h 사람 친화적 숫자 정렬(1K, 2M…).
$ du -sh * | sort -rh  # 용량 큰 파일 순
uniq
연속된 중복 줄 제거
반드시 sort 후에 사용. -c 중복 횟수 표시 · -d 중복된 줄만 출력.
$ sort access.log | uniq -c | sort -rn | head -10
wc [파일]
줄 수·단어 수·바이트 수 출력
-l 줄 수만 · -w 단어 수만 · -c 바이트만.
$ wc -l *.py  # Python 파일 총 줄 수
cut -d: -f1
구분자(:)로 나눈 첫 번째 필드 추출
-d 구분자 · -f 필드 번호. /etc/passwd 파싱 등에 활용.
$ cut -d: -f1 /etc/passwd  # 사용자 이름만
tr 'a-z' 'A-Z'
문자 변환 또는 삭제
-d 문자 삭제 · -s 연속된 같은 문자 하나로 압축.
$ echo "hello" | tr 'a-z' 'A-Z' → HELLO
05 파이프 & 리디렉션
cmd1 | cmd2
파이프: 앞 명령어 출력을 뒤 명령어 입력으로 전달
터미널의 핵심 철학. 작은 도구를 조합해 강력한 작업 수행.
$ ps aux | grep nginx | grep -v grep
cmd > file
출력을 파일로 저장 (덮어쓰기)
기존 파일 내용이 사라짐. 이어 쓰려면 >> 사용.
$ ls -la > list.txt
cmd 2> file
에러 출력(stderr)을 파일로 저장
2>&1 에러를 표준 출력으로 합치기. > out.txt 2>&1 정상+에러 모두 파일로.
$ make 2> errors.txt
tee [파일]
출력을 화면과 파일에 동시에 저장
파이프 중간에 넣어서 실시간으로 보면서 파일에도 저장.
$ make 2>&1 | tee build.log
xargs
표준 입력을 인수로 변환해 명령 실행
파이프로 넘어온 목록을 다음 명령어의 인수로 사용.
$ find . -name "*.tmp" | xargs rm -f
🔒 권한 · 프로세스 · 사용자
파일 권한 관리, 실행 중인 프로세스 제어, 사용자 전환
01 파일 권한 (chmod · chown)
chmod 755 파일
파일 권한 변경 (숫자 방식)
r=4, w=2, x=1 합산. 755 = 소유자(7:rwx) 그룹(5:r-x) 기타(5:r-x). 644 = 소유자 읽기쓰기, 나머지 읽기만.
$ chmod 755 script.sh  # 실행 가능하게
chmod +x 파일
실행 권한 추가 (기호 방식)
u 소유자 · g 그룹 · o 기타 · a 전체. + 추가 · - 제거 · = 설정.
$ chmod u+x,go-w script.sh
chown user:group 파일
파일 소유자 및 그룹 변경
-R 재귀 적용 (디렉토리 전체). root 권한 필요.
$ sudo chown -R www-data:www-data /var/www/html
ls -l
파일 권한 확인
-rwxr-xr-x 형태로 표시. 첫 문자: -파일 d디렉토리 l링크. 이후 3자씩 소유자/그룹/기타 권한.
02 프로세스 관리
ps aux
실행 중인 프로세스 목록 전체 출력
a 모든 사용자 · u 소유자 포함 · x 터미널 없는 프로세스도 표시.
$ ps aux | grep node
top
실시간 프로세스 모니터 (CPU/메모리 순)
P CPU순 · M 메모리순 · k PID 입력 후 kill · q 종료. htop 설치 시 더 편리.
kill PID
특정 PID 프로세스에 신호 전송 (종료)
-9 강제 종료(SIGKILL) · -15 정상 종료(SIGTERM, 기본값) · -1 재시작(SIGHUP).
$ kill -9 1234
pkill [프로세스명]
이름으로 프로세스 종료
PID를 찾지 않고 이름으로 바로 종료. -f 인수까지 포함해 검색.
$ pkill -f "python app.py"
cmd &
명령어를 백그라운드에서 실행
Ctrl+Z 현재 프로세스 일시정지 → bg 백그라운드 재개 · fg 포그라운드로 복귀 · jobs 백그라운드 작업 목록.
$ python server.py &
nohup cmd &
터미널 종료 후에도 계속 실행
SSH 접속 끊어도 프로세스 유지. 출력은 nohup.out에 저장.
$ nohup ./server.sh > server.log 2>&1 &
03 사용자 & sudo
sudo [명령어]
관리자 권한으로 명령 실행
Superuser Do. 비밀번호 입력 후 기본 15분간 캐시. sudo -i root 쉘로 전환.
su [사용자]
다른 사용자 계정으로 전환
su - root 로그인 쉘로 전환 (환경변수까지 변경). exit로 복귀.
whoami
현재 사용자 이름 출력
sudo 후 실제 어떤 계정인지 확인할 때 유용.
id
현재 사용자 UID, GID, 그룹 정보
uid=1000(user) gid=1000(user) groups=... 형태로 출력.
passwd
비밀번호 변경
sudo passwd 사용자명 으로 다른 사용자 비밀번호 변경.
04 환경변수 & 쉘 설정
export VAR=값
환경변수 설정 (현재 세션 + 자식 프로세스)
영구 적용하려면 ~/.bashrc 또는 ~/.zshrc에 추가.
$ export PATH="$PATH:/usr/local/bin"
env
현재 환경변수 전체 출력
env | grep PATH 처럼 특정 변수만 확인.
echo $VAR
특정 환경변수 값 출력
$ echo $HOME · $PATH · $SHELL · $USER 등.
source ~/.bashrc
설정 파일 현재 쉘에 즉시 적용
. (점)도 동일 기능. 재로그인 없이 .bashrc/.zshrc 변경 사항 반영.
alias 이름='명령'
명령어 별명(단축키) 만들기
~/.bashrc에 추가하면 영구 적용.
$ alias ll='ls -lah'  |  $ alias gs='git status'
🌐 네트워크
연결 확인, 파일 다운로드, 포트 확인, SSH 접속 등
01 연결 확인 & 진단
ping 호스트
대상 호스트에 ICMP 패킷 전송해 응답 확인
-c 4 4번만 보내고 종료 · -i 0.5 0.5초 간격. Ctrl+C로 중단.
$ ping -c 4 google.com
traceroute 호스트
목적지까지 경유 라우터 경로 추적
네트워크 지연 원인 진단에 사용. macOS는 traceroute, Windows는 tracert.
nslookup 도메인
도메인의 DNS 레코드 조회
IP 주소, MX 레코드 등 확인. dig 명령어가 더 상세한 정보 제공.
$ nslookup github.com
netstat -tuln
열린 포트 및 연결 상태 확인
-t TCP · -u UDP · -l LISTEN 상태 · -n 숫자로. 최신 시스템은 ss 명령어 사용.
$ ss -tuln | grep 8080
ifconfig / ip addr
네트워크 인터페이스 및 IP 주소 확인
ifconfig는 구버전, 최신 리눅스는 ip addr show 권장.
02 파일 다운로드 & 전송
curl URL
URL로 데이터 전송/수신 (HTTP, FTP 등)
-O 파일명 유지 다운로드 · -o 파일명 저장 · -I 헤더만 · -X POST 메서드 지정 · -H 헤더 추가.
$ curl -O https://example.com/file.zip
$ curl -X POST -H "Content-Type: application/json" -d '{"key":"val"}' https://api.example.com/
wget URL
파일 다운로드 전용 도구

. 전체 변경 · -p 변경 사항을 조각 단위로 선택적 추가.
$ git add src/app.js  |  $ git add -p

스테이징된 변경 사항 커밋
--amend 직전 커밋 수정 · -a 추적 중인 파일 자동 스테이징 후 커밋.

git branch
브랜치 목록 확인
-a 원격 포함 전체 · -d 브랜치명 브랜치 삭제 · -D 강제 삭제.
git checkout -b 브랜치명
새 브랜치 생성 후 전환
최신 Git에서는 git switch -c 브랜치명 권장.
$ git checkout -b feat/login
git merge 브랜치명
지정 브랜치를 현재 브랜치에 병합
--no-ff 항상 병합 커밋 생성 · --squash 커밋 압축 후 병합.
git rebase 브랜치명
현재 브랜치 커밋을 대상 브랜치 끝에 재배치
선형 히스토리 유지. 공유 브랜치에는 사용 주의.
git stash

pop 마지막 stash 복원 후 삭제 · list 목록 · apply 삭제 없이 복원 · -u 미추적 파일도 포함.
$ git stash -u  |  $ git stash pop
03 히스토리 & 되돌리기
git log --oneline
커밋 히스토리 한 줄씩 표시
--graph --all 브랜치 그래프 · -n 10 최근 10개 · --author="이름" 특정 사람 커밋.
$ git log --oneline --graph --all
git diff [파일]
변경 사항 비교
--staged 스테이징된 변경 · 브랜치A..브랜치B 브랜치 간 비교.
git reset HEAD~1
직전 커밋 취소 (변경 사항은 유지)
--soft 스테이징 유지 · --mixed 스테이징 해제(기본) · --hard 변경사항까지 삭제.
--hard는 복구 어려움. git reflog로 확인 가능.
git revert SHA
특정 커밋의 반대 커밋 생성 (안전한 되돌리기)
히스토리를 지우지 않고 되돌림. 공유 브랜치에서 reset 대신 권장.
git cherry-pick SHA
다른 브랜치의 특정 커밋만 가져오기
hotfix를 main에도 적용하는 등 선택적 커밋 이식에 활용.
git reflog
HEAD 이동 이력 전체 조회
reset --hard로 지운 커밋도 복구 가능. git의 최후 안전망.
